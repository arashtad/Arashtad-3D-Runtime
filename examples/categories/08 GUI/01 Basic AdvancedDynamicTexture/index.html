AdvancedDynamicTexture

An AdvancedDynamicTexture provides the root surface for Babylon.js GUI controls. No individual control is added in this example; controls are introduced in the next examples.

GUI Root

The runtime creates an AdvancedDynamicTexture from the arashtad-gui element.

The element has the runtime ID ui. This ID can later be used by GUI controls as their parent.

The basic GUI hierarchy introduced here is:

AdvancedDynamicTexture
