Basic GUI Button

103

Create an interactive GUI button and respond to its pointer click event.

GUI Button
Click the button to trigger an action.

Interactive Button

A Button is created as a child of the AdvancedDynamicTexture and responds to OnPointerClick. The click action updates the page status to demonstrate that the GUI event was received.

Button

The button uses the runtime ID button and is attached to the GUI root using parent="ui".

The OnPointerClick attribute contains JavaScript that runs when the button is clicked.

In this example, the action updates the HTML status element outside the Babylon.js canvas.

Source

The button is created declaratively and its pointer click behavior is defined directly on the runtime element. 

<arashtad-gui
    id="ui"
    type="AdvancedDynamicTexture">
</arashtad-gui>

<arashtad-gui
    id="button"
    type="Button"
    parent="ui"
    text="CLICK ME"
    width="'200px'"
    height="'60px'"
    color="'white'"
    background="'#26a38c'"
    fontSize="24"
    cornerRadius="10"
    OnPointerClick="
        document.getElementById('gui-status').innerHTML =
            '<strong>Button clicked</strong><br>GUI pointer interaction is working.';
    ">
</arashtad-gui>
