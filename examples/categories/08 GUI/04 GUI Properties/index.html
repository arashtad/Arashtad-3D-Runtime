GUI Properties

GUI controls expose properties that can be configured directly through runtime attributes. This example combines dimensions, colors, typography, corner radius, position, and alignment.

Button Properties

width and height define the button dimensions.

color defines the text color, while background defines the button background.

fontSize controls the text size and cornerRadius controls the rounded corners.

top, left, verticalAlignment, and horizontalAlignment control the button's position within the GUI.

The click action also demonstrates that these properties can be modified after the control has been created.

Source

GUI properties are declared directly as attributes on the runtime element. 

<arashtad-gui
    id="button"
    type="Button"
    parent="ui"
    text="GUI PROPERTIES"
    width="'280px'"
    height="'70px'"
    color="'white'"
    background="'#26a38c'"
    fontSize="24"
    cornerRadius="12"
    top="'0px'"
    left="'0px'"
    verticalAlignment="1"
    horizontalAlignment="1"
    OnPointerClick="
        button.background = '#ff9000';
    ">
</arashtad-gui>
