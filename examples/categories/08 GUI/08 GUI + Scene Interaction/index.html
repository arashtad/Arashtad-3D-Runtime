INTERACTIVE REACTOR
The camera rotates automatically. Use the GUI or click the square meshes directly.

GUI + Scene Interaction

GUI controls can manipulate scene objects through runtime references while individual 3D meshes respond to pointer interaction.

Camera Auto Rotation

The ArcRotateCamera uses its built-in automatic rotation behavior, allowing the complete assembly to continuously rotate in the viewer.

The scene therefore remains visually active without requiring a separate animation loop.

GUI → Scene

ROTATE SQUARES rotates the three box meshes while leaving the circular rings and sphere untouched.

RANDOM COLORS generates new random RGB values every time it is clicked.

There is no fixed color set, so the button can produce an unlimited sequence of combinations.

Scene → GUI

The square meshes also have their own pointer actions, demonstrating direct interaction with scene objects independently of the GUI.

Direct Mesh Interaction

Click the central square or either side square directly in the 3D scene to rotate it.

The circular meshes remain stationary when the square-mesh interaction is triggered.

Runtime References

GUI actions access scene objects through refs.

IDs containing hyphens are accessed using bracket notation such as refs['left-module'].

Source

The example combines camera behavior, GUI controls, random material generation, and direct mesh pointer actions. 

<arashtad-camera
    type="ArcRotateCamera"
    id="camera"
    args="Math.PI / 2, Math.PI / 2.7, 13, new BABYLON.Vector3(0, 1.5, 0)"
    useAutoRotationBehavior="true">
</arashtad-camera>

<arashtad-gui
    id="color-button"
    type="Button"
    parent="ui"
    text="RANDOM COLORS"
    OnPointerClick="
        refs['core-material'].diffuseColor =
            new BABYLON.Color3(Math.random(), Math.random(), Math.random());

        refs['ring-material'].diffuseColor =
            new BABYLON.Color3(Math.random(), Math.random(), Math.random());

        refs['secondary-material'].diffuseColor =
            new BABYLON.Color3(Math.random(), Math.random(), Math.random());
    ">
</arashtad-gui>

<arashtad-gui
    id="rotate-button"
    type="Button"
    parent="ui"
    text="ROTATE SQUARES"
    OnPointerClick="
        refs['core'].rotation.y += Math.PI / 4;
        refs['left-module'].rotation.z += Math.PI / 4;
        refs['right-module'].rotation.z -= Math.PI / 4;
    ">
</arashtad-gui>
