GUI Parent / Control Relationship

GUI Parent/Control Relationship

106

Attach a GUI control to an AdvancedDynamicTexture using the runtime parent relationship.

Parent / Control
The Button is attached to the GUI root.

GUI Hierarchy

GUI controls are attached to an AdvancedDynamicTexture through the parent attribute. The parent establishes where the control belongs in the GUI hierarchy.

Parent / Control

The AdvancedDynamicTexture has the runtime ID ui.

The Button has the runtime ID button and declares parent="ui".

This creates the following relationship:

ui → button

The Button is therefore created as a control belonging to the GUI root rather than as an independent scene object.

Clicking the Button confirms that the control has been created and attached to its GUI parent.

Source

The parent attribute connects the Button to the AdvancedDynamicTexture. 

<arashtad-gui
    id="ui"
    type="AdvancedDynamicTexture">
</arashtad-gui>

<arashtad-gui
    id="button"
    type="Button"
    parent="ui"
    text="GUI CONTROL"
    width="'240px'"
    height="'70px'"
    color="'white'"
    background="'#26a38c'"
    fontSize="24"
    cornerRadius="10">
</arashtad-gui>
