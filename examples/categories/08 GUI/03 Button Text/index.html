Button Text

The text attribute sets the initial visible text of a GUI Button. The button also exposes its internal text block, allowing its displayed text to be changed after creation.

Text Configuration

The button is created with text="CHANGE TEXT".

Its click action changes the displayed text through button.textBlock.text.

This demonstrates both declarative button text and runtime text modification.

Source

The Button text is defined with the runtime text attribute and can be changed through the Button's text block. 

<arashtad-gui
    id="button"
    type="Button"
    parent="ui"
    text="CHANGE TEXT"
    width="'220px'"
    height="'60px'"
    color="'white'"
    background="'#26a38c'"
    fontSize="24"
    cornerRadius="10"
    OnPointerClick="
        button.textBlock.text = 'TEXT CHANGED';
    ">
</arashtad-gui>
