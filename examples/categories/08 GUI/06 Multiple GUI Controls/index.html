Multiple GUI Controls

An AdvancedDynamicTexture can contain multiple independent controls. Each Button has its own properties and pointer action while sharing the same GUI root.

GUI Control Hierarchy

All three buttons use parent="ui", so they belong to the same AdvancedDynamicTexture.

ROTATE changes the 3D object's Y rotation.

SCALE enlarges the 3D object.

RESET restores the object's original rotation and scale.

The GUI therefore acts as a control layer for the 3D scene.

Because the mesh ID contains a hyphen, the runtime reference is accessed as refs['main-object'].

Source

Multiple Button controls can share one AdvancedDynamicTexture and independently manipulate runtime scene objects. 

<arashtad-gui
    id="ui"
    type="AdvancedDynamicTexture">
</arashtad-gui>

<arashtad-gui
    id="rotate-button"
    type="Button"
    parent="ui"
    text="ROTATE"
    width="'150px'"
    height="'52px'"
    color="'white'"
    background="'#26a38c'"
    fontSize="20"
    cornerRadius="8"
    top="'24px'"
    left="'24px'"
    verticalAlignment="0"
    horizontalAlignment="0"
    OnPointerClick="
        refs['main-object'].rotation.y += Math.PI / 4;
    ">
</arashtad-gui>

<arashtad-gui
    id="scale-button"
    type="Button"
    parent="ui"
    text="SCALE"
    width="'150px'"
    height="'52px'"
    color="'white'"
    background="'#ff9000'"
    fontSize="20"
    cornerRadius="8"
    top="'84px'"
    left="'24px'"
    verticalAlignment="0"
    horizontalAlignment="0"
    OnPointerClick="
        refs['main-object'].scaling.scaleInPlace(1.2);
    ">
</arashtad-gui>

<arashtad-gui
    id="reset-button"
    type="Button"
    parent="ui"
    text="RESET"
    width="'150px'"
    height="'52px'"
    color="'white'"
    background="'#303b46'"
    fontSize="20"
    cornerRadius="8"
    top="'144px'"
    left="'24px'"
    verticalAlignment="0"
    horizontalAlignment="0"
    OnPointerClick="
        refs['main-object'].rotation = new BABYLON.Vector3(0, 0, 0);
        refs['main-object'].scaling = new BABYLON.Vector3(1, 1, 1);
    ">
</arashtad-gui>
