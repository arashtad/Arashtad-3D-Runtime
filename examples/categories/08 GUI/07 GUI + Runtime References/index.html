GUI + Runtime References

108

Use runtime references inside GUI actions to control scene objects and other runtime elements.

Runtime References
GUI actions can access other runtime elements through refs.

Runtime References

GUI actions execute inside the runtime reference context. Elements created by the runtime can be accessed through the refs object.

Using refs

The 3D mesh is registered with the ID main-object. Because the ID contains a hyphen, it is accessed as refs['main-object'].

The material is registered as object-material and is accessed as refs['object-material'].

GUI controls are runtime references as well. The Reset button accesses refs['rotate-button'] and refs['color-button'] to restore their backgrounds.

This allows GUI controls to operate as a declarative control layer over the rest of the runtime scene.

Source

GUI actions access meshes, materials, and other GUI controls through the runtime refs object. 

OnPointerClick="
    refs['main-object'].rotation.y += Math.PI / 4;
"

OnPointerClick="
    refs['object-material'].diffuseColor =
        new BABYLON.Color3(0.95, 0.56, 0.08);

    refs['main-object'].material =
        refs['object-material'];
"

OnPointerClick="
    refs['main-object'].rotation =
        new BABYLON.Vector3(0, 0, 0);

    refs['main-object'].scaling =
        new BABYLON.Vector3(1, 1, 1);

    refs['object-material'].diffuseColor =
        new BABYLON.Color3(0.15, 0.64, 0.55);

    refs['rotate-button'].background = '#26a38c';
    refs['color-button'].background = '#ff9000';
"
