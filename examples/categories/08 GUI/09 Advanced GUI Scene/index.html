A Complete GUI-Controlled Application

This example combines model, material, particle, lighting, and GUI features into a single application-style interface.

Product Control

The imported model is displayed as the main product object. Its imported mesh is connected to an external runtime material.

The material controls therefore modify the appearance of the actual imported model mesh.

Scene Control

The GUI controls material color, lighting intensity, particle effects, and a complete presentation configuration.

Scene Systems

Several independent runtime systems are controlled through one GUI.

Material Control

TEAL, ORANGE, and RANDOM FINISH modify the material assigned to the imported model mesh.

Lighting + Effects

Lighting buttons change the intensity of the scene lights, while the particle controls start and stop the particle system.

Source

GUI controls access runtime references directly through refs. 

<arashtad-gui
    id="orange-button"
    type="Button"
    parent="ui"
    text="ORANGE"
    OnPointerClick="
        refs['accent-material'].diffuseColor =
            new BABYLON.Color3(0.95, 0.56, 0.08);
    ">
</arashtad-gui>

<arashtad-gui
    id="particles-button"
    type="Button"
    parent="ui"
    text="START EFFECT"
    OnPointerClick="
        refs['particles'].start();
    ">
</arashtad-gui>

<arashtad-gui
    id="lights-up-button"
    type="Button"
    parent="ui"
    text="LIGHT +"
    OnPointerClick="
        refs['key-light'].intensity =
            Math.min(refs['key-light'].intensity + 0.5, 8);
    ">
</arashtad-gui>
