Rotation and Scaling: Nested Properties

Nested Property Paths

The runtime supports dot notation for properties such as rotation and scaling.

Properties

rotation.x = 30°

rotation.y = 45°

scaling.x = 1.5

scaling.y = 0.8

scaling.z = 1.2

Source

Nested properties use dot notation in the runtime markup. 

<arashtad-mesh
    type="Box"
    id="nested-mesh"
    size="2"
    position="new BABYLON.Vector3(0, 0, 0)"
    rotation.x="Math.PI / 6"
    rotation.y="Math.PI / 4"
    scaling.x="1.5"
    scaling.y="0.8"
    scaling.z="1.2">
</arashtad-mesh>
