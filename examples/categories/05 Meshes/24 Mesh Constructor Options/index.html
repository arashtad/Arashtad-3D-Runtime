Cylinder Options

Height: 4

Source

The runtime parses the args expression and passes the resulting options object to the corresponding MeshBuilder factory. 

<arashtad-mesh
    type="Cylinder"
    id="constructor-mesh"
    args="{
        height: 4,
        diameter: 2.5,
        tessellation: 8
    }"
    position="new BABYLON.Vector3(0, 2, 0)">
</arashtad-mesh>
