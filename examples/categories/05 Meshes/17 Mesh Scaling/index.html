Scaling

The scaling attribute accepts a Babylon.js Vector3. Each component independently controls the scale of the mesh along the X, Y, and Z axes.

Scale Components

X scale: 2

Y scale: 1

Z scale: 0.5

A value of 1 preserves the original size.

Source

Complete source for the mesh scaling example. 

<arashtad-mesh
    id="scaling-mesh"
    type="Box"
    size="2"
    position="new BABYLON.Vector3(0, 0, 0)"
    scaling="new BABYLON.Vector3(2, 1, 0.5)">
</arashtad-mesh>
