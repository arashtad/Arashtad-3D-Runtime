Cylinder

61

Create a cylindrical mesh with configurable height, diameter, tessellation, and cap settings.

Mesh: Cylinder

Cylinder Parameters

The runtime passes the cylinder attributes directly to Babylon.js MeshBuilder.

Geometry

height controls the vertical size, while diameter controls the circular cross-section.

tessellation controls the number of radial segments, and subdivisions divides the cylinder along its height.

Source

Use type="Cylinder" and provide the desired MeshBuilder options as runtime attributes. 

<arashtad-mesh type="Cylinder" id="cylinder-mesh"
    height="3"
    diameter="2"
    tessellation="32"
    subdivisions="1"
    position="new BABYLON.Vector3(0, 1.5, 0)">
</arashtad-mesh>
