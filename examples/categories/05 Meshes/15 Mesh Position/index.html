Set a mesh position using a Babylon.js Vector3 expression.

Mesh Position
Position: X 2 · Y 1 · Z −1

Position

The position attribute accepts a Babylon.js Vector3 expression that defines the mesh location in three-dimensional space.

Vector3 Position

The X coordinate controls horizontal placement.

The Y coordinate controls vertical placement.

The Z coordinate controls depth placement.

This example places the box at (2, 1, -1).

Source

Complete source for the mesh position example. 

<arashtad-mesh
    id="position-mesh"
    type="Box"
    size="2"
    position="new BABYLON.Vector3(2, 1, -1)">
</arashtad-mesh>
