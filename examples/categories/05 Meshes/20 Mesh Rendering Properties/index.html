Control mesh rendering properties such as outlines, overlay rendering, and pickability at runtime.

Outline: On · Pickable: On

Rendering Controls

Change mesh rendering properties directly on the Babylon.js mesh.

Mesh Properties

Source

Rendering properties are modified directly on the mesh after the runtime initializes. 

<arashtad-mesh
    type="Box"
    id="rendering-mesh"
    size="2"
    renderOutline="true"
    outlineWidth="0.05"
    outlineColor="new BABYLON.Color3(0.15, 0.64, 0.55)"
    isPickable="true">
</arashtad-mesh>

const scene = await ready(canvas);

const mesh = scene.meshes.find(
    mesh => mesh.name === 'rendering-mesh'
);

outlineToggle.addEventListener('change', () => {
    mesh.renderOutline = outlineToggle.checked;
});

pickableToggle.addEventListener('change', () => {
    mesh.isPickable = pickableToggle.checked;
});

overlayToggle.addEventListener('change', () => {
    mesh.overlayRendering = overlayToggle.checked;
});
