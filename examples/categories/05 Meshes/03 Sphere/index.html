Create a sphere mesh using Babylon.js MeshBuilder through the Arashtad 3D Runtime.

Mesh: Sphere

Sphere Parameters

The runtime passes the mesh attributes to Babylon.js MeshBuilder as sphere creation options.

Geometry

The diameter attribute controls the overall size of the sphere, while segments controls its geometric subdivisions.

Additional MeshBuilder options can be supplied directly as runtime attributes.

Source

Create a sphere with type="Sphere" and provide its geometry options as attributes. 

<arashtad-mesh type="Sphere" id="sphere-mesh"
    diameter="2"
    segments="32"
    position="new BABYLON.Vector3(0, 0, 0)">
</arashtad-mesh>
