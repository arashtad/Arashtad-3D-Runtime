Lathe

68

Create a rotationally generated mesh from a profile using Babylon.js MeshBuilder through the Arashtad 3D Runtime.

Mesh: Lathe

Lathe Parameters

The Lathe mesh revolves a profile around an axis to create a rotationally symmetric surface.

Configuration

shape - Ordered Vector3 points defining the profile.

radius - Radial scale applied to the profile.

tessellation - Number of segments around the rotational axis.

sideOrientation - Determines face orientation.

position - World-space position of the mesh.

Source

The complete runtime markup used to create the lathed mesh. 

<canvas id="lathe"
    clearColor="new BABYLON.Color4(0.008, 0.012, 0.018, 1)">

    <arashtad-runtime resize="engine.resize()"></arashtad-runtime>

    <arashtad-camera type="ArcRotateCamera" id="camera"
        args="Math.PI / 2, Math.PI / 2.6, 8, new BABYLON.Vector3(0, 1.2, 0)"
        minZ="0.1"
        maxZ="1000">
    </arashtad-camera>

    <arashtad-light type="HemisphericLight" id="light"
        args="new BABYLON.Vector3(0, 1, 0)"
        intensity="1.3">
    </arashtad-light>

    <arashtad-mesh type="Lathe" id="lathe-mesh"
        shape="[
            new BABYLON.Vector3(0.6, 0, 0),
            new BABYLON.Vector3(0.9, 0.4, 0),
            new BABYLON.Vector3(0.75, 0.9, 0),
            new BABYLON.Vector3(1.2, 1.4, 0),
            new BABYLON.Vector3(0.9, 2.0, 0),
            new BABYLON.Vector3(0.5, 2.4, 0)
        ]"
        radius="1"
        tessellation="48"
        sideOrientation="BABYLON.Mesh.DOUBLESIDE"
        position="new BABYLON.Vector3(0, -1.2, 0)">
    </arashtad-mesh>

</canvas>
