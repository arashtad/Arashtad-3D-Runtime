Mesh Material

80

Assign a Babylon.js material to a mesh using an Arashtad 3D Runtime reference.

Material: box-material

Material Assignment

The material is created as a runtime object and assigned to the mesh through its reference.

Mesh Material

Mesh: material-mesh

Material: box-material

Type: StandardMaterial

Source

The material reference connects the mesh to the material created in the scene. 

<arashtad-material
    type="StandardMaterial"
    id="box-material"
    diffuseColor="new BABYLON.Color3(0.15, 0.64, 0.55)"
    specularColor="new BABYLON.Color3(0.8, 0.8, 0.8)">
</arashtad-material>

<arashtad-mesh
    type="Box"
    id="material-mesh"
    size="2"
    material="box-material">
</arashtad-mesh>
