Mesh Visibility

76

Change mesh visibility interactively using a switch.

Visibility

The mesh starts fully visible. The switch changes its visibility property between 1 and 0.

Interactive Visibility

Switch on: visibility = 1

Switch off: visibility = 0

The property is changed directly on the registered mesh after the runtime has initialized.

Source

Complete source for the mesh visibility example. 

<arashtad-mesh
    type="Box"
    id="visibility-mesh"
    size="2"
    position="new BABYLON.Vector3(0, 0, 0)"
    visibility="1">
</arashtad-mesh>

<label class="visibility-switch">
    <input
        id="visibility-toggle"
        type="checkbox"
        checked
    >
    <span class="visibility-slider"></span>
    <span id="visibility-label">Visible</span>
</label>

<script>
const toggle = document.getElementById('visibility-toggle');
const label = document.getElementById('visibility-label');

toggle.addEventListener('change', () => {
    const mesh = BABYLON.Meshes[0];

    mesh.visibility = toggle.checked ? 1 : 0;
    label.textContent = toggle.checked ? 'Visible' : 'Hidden';
});
</script>
