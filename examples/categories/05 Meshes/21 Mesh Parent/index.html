Mesh Parent

79

Parent a mesh to another mesh so that the child follows the parent's transformations.

Child Parent: parent-mesh

Mesh Hierarchy

The sphere is assigned to the box as its parent after the scene is initialized. Rotate the box to see the child follow it.

Parent Relationship

Parent: parent-mesh

Child: child-mesh

Click the box in the scene to rotate the parent and its child.

Source

The child mesh is assigned to the parent through the Babylon.js mesh API. 

<arashtad-mesh
    type="Box"
    id="parent-mesh"
    size="2"
    position="new BABYLON.Vector3(0, 0, 0)"
    OnPickTrigger="rotation.y += 0.5">
</arashtad-mesh>

<arashtad-mesh
    type="Sphere"
    id="child-mesh"
    diameter="1"
    position="new BABYLON.Vector3(0, 2, 0)">
</arashtad-mesh>

const scene = await ready(canvas);

const parent = scene.meshes.find(
    mesh => mesh.name === 'parent-mesh'
);

const child = scene.meshes.find(
    mesh => mesh.name === 'child-mesh'
);

child.parent = parent;
