Create a procedural torus knot mesh using Babylon.js MeshBuilder through the Arashtad 3D Runtime.

Mesh: Torus Knot

Torus Knot Parameters

The Torus Knot mesh generates a parametric knot. The radius and tube determine its overall proportions, while p and q define the knot path.

Configuration

radius - Radius of the knot path.

tube - Radius of the tubular section.

radialSegments - Number of radial segments.

tubularSegments - Number of segments along the tube.

p - Number of times the curve winds around the axis.

q - Number of times the curve winds through the hole.

position - World-space position of the mesh.

Source

The complete runtime markup used to create the torus knot. 

<canvas id="torus-knot"
    clearColor="new BABYLON.Color4(0.008, 0.012, 0.018, 1)">

    <arashtad-runtime resize="engine.resize()"></arashtad-runtime>

    <arashtad-camera type="ArcRotateCamera" id="camera"
        args="Math.PI / 2, Math.PI / 2.4, 8, new BABYLON.Vector3(0, 0, 0)"
        minZ="0.1"
        maxZ="1000">
    </arashtad-camera>

    <arashtad-light type="HemisphericLight" id="light"
        args="new BABYLON.Vector3(0, 1, 0)"
        intensity="1.3">
    </arashtad-light>

    <arashtad-mesh type="TorusKnot" id="torus-knot-mesh"
        radius="2"
        tube="0.55"
        radialSegments="64"
        tubularSegments="32"
        p="2"
        q="3"
        position="new BABYLON.Vector3(0, 0, 0)">
    </arashtad-mesh>

</canvas>
