Polygon mesh

Polygon

67

Create a custom polygon mesh from an ordered set of three-dimensional vertices using Babylon.js MeshBuilder through the Arashtad 3D Runtime.

Mesh: Polygon

Polygon Parameters

The Polygon mesh is generated from an ordered 2D contour represented by Babylon.js Vector3 points. The contour is then extruded to the specified depth.

Configuration

shape - Ordered array of Vector3 points defining the polygon contour.

depth - Depth of the extruded polygon.

sideOrientation - Determines polygon face orientation.

position - World-space position of the mesh.

Source

The complete runtime markup used to create the polygon mesh. 

<canvas id="polygon"
    clearColor="new BABYLON.Color4(0.008, 0.012, 0.018, 1)">

    <arashtad-runtime resize="engine.resize()"></arashtad-runtime>

    <arashtad-camera type="ArcRotateCamera" id="camera"
        args="Math.PI / 2, Math.PI / 2.5, 8, new BABYLON.Vector3(0, 0.5, 0)"
        minZ="0.1"
        maxZ="1000">
    </arashtad-camera>

    <arashtad-light type="HemisphericLight" id="light"
        args="new BABYLON.Vector3(0, 1, 0)"
        intensity="1.3">
    </arashtad-light>

    <arashtad-mesh type="Polygon" id="polygon-mesh"
        shape="[
            new BABYLON.Vector3(-2.5, 0, -1.5),
            new BABYLON.Vector3(-1, 0, 1.5),
            new BABYLON.Vector3(1.5, 0, 1.2),
            new BABYLON.Vector3(2.5, 0, -0.5),
            new BABYLON.Vector3(0.8, 0, -2),
            new BABYLON.Vector3(-1.5, 0, -2)
        ]"
        depth="0.6"
        sideOrientation="BABYLON.Mesh.DOUBLESIDE"
        position="new BABYLON.Vector3(0, 0, 0)">
    </arashtad-mesh>

</canvas>
