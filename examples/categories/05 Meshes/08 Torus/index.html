Create a torus mesh with configurable diameter, thickness, tessellation, and radial segments using Babylon.js MeshBuilder.

Mesh: Torus

Torus Parameters

The Torus mesh forms a ring around its center. Its diameter controls the overall size, thickness controls the tube radius, and tessellation and subdivisions control geometric detail.

Configuration

diameter - Overall diameter of the torus.

thickness - Thickness of the torus tube.

tessellation - Number of segments around the torus.

subdivisions - Number of segments around the tube.

position - World-space position of the mesh.

Source

The complete runtime markup used to create the torus mesh. 

<canvas id="torus"
    clearColor="new BABYLON.Color4(0.008, 0.012, 0.018, 1)">

    <arashtad-runtime resize="engine.resize()"></arashtad-runtime>

    <arashtad-camera type="ArcRotateCamera" id="camera"
        args="Math.PI / 2, Math.PI / 2.4, 7, new BABYLON.Vector3(0, 0, 0)"
        minZ="0.1"
        maxZ="1000">
    </arashtad-camera>

    <arashtad-light type="HemisphericLight" id="light"
        args="new BABYLON.Vector3(0, 1, 0)"
        intensity="1.3">
    </arashtad-light>

    <arashtad-mesh type="Torus" id="torus-mesh"
        diameter="4"
        thickness="1"
        tessellation="48"
        subdivisions="24"
        position="new BABYLON.Vector3(0, 0, 0)">
    </arashtad-mesh>

</canvas>
