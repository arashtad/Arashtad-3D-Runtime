Plane

59

Create a flat rectangular mesh using Babylon.js MeshBuilder through the Arashtad 3D Runtime.

Mesh: Plane

Plane Parameters

The runtime passes the plane attributes directly to Babylon.js MeshBuilder.

Dimensions

The width and height attributes define the dimensions of the rectangular surface.

sideOrientation is set to BABYLON.Mesh.DOUBLESIDE so the plane is visible from both sides.

Source

Use type="Plane" with width and height attributes as MeshBuilder options. 

<arashtad-mesh type="Plane" id="plane-mesh"
    width="5"
    height="3"
    sideOrientation="BABYLON.Mesh.DOUBLESIDE"
    position="new BABYLON.Vector3(0, 0, 0)">
</arashtad-mesh>
