Combining Mesh Types

A composed object can be built from multiple independent meshes, each using its own geometry and transform.

Composition

Base - Box

Columns - Cylinders

Top - Sphere

Ground - Ground mesh

Source

Each mesh is declared independently while their positions combine them into one composed structure. 

<arashtad-mesh
    type="Box"
    id="base-mesh"
    width="5"
    height="0.6"
    depth="3"
    position="new BABYLON.Vector3(0, 0.3, 0)">
</arashtad-mesh>

<arashtad-mesh
    type="Cylinder"
    id="left-column"
    height="3"
    diameter="1"
    tessellation="24"
    position="new BABYLON.Vector3(-1.8, 1.8, 0)">
</arashtad-mesh>

<arashtad-mesh
    type="Cylinder"
    id="right-column"
    height="3"
    diameter="1"
    tessellation="24"
    position="new BABYLON.Vector3(1.8, 1.8, 0)">
</arashtad-mesh>

<arashtad-mesh
    type="Sphere"
    id="top-mesh"
    diameter="2.2"
    position="new BABYLON.Vector3(0, 3.5, 0)">
</arashtad-mesh>

<arashtad-mesh
    type="Ground"
    id="ground-mesh"
    width="10"
    height="7"
    position="new BABYLON.Vector3(0, 0, 0)">
</arashtad-mesh>
