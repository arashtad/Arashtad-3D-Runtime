Create a tubular mesh along a three-dimensional path using Babylon.js MeshBuilder through the Arashtad 3D Runtime.

Mesh: Tube

Tube Parameters

The Tube mesh follows a sequence of three-dimensional points and generates a cylindrical surface around that path.

Configuration

path - Ordered array of Babylon.js Vector3 points defining the tube path.

radius - Radius of the tube.

tessellation - Number of segments around the tube cross-section.

Source

The complete runtime markup used to create the tube mesh. 

<canvas id="tube"
    clearColor="new BABYLON.Color4(0.008, 0.012, 0.018, 1)">

    <arashtad-runtime resize="engine.resize()"></arashtad-runtime>

    <arashtad-camera type="ArcRotateCamera" id="camera"
        args="Math.PI / 2, Math.PI / 2.5, 10, new BABYLON.Vector3(0, 0, 0)"
        minZ="0.1"
        maxZ="1000">
    </arashtad-camera>

    <arashtad-light type="HemisphericLight" id="light"
        args="new BABYLON.Vector3(0, 1, 0)"
        intensity="1.3">
    </arashtad-light>

    <arashtad-mesh type="Tube" id="tube-mesh"
        path="[
            new BABYLON.Vector3(-4, 0, 0),
            new BABYLON.Vector3(-3, 1.5, 0),
            new BABYLON.Vector3(-1.5, 2, 0),
            new BABYLON.Vector3(0, 0, 0),
            new BABYLON.Vector3(1.5, -2, 0),
            new BABYLON.Vector3(3, -1.5, 0),
            new BABYLON.Vector3(4, 0, 0)
        ]"
        radius="0.45"
        tessellation="32">
    </arashtad-mesh>

</canvas>
