Multiple Meshes

83

Create multiple independent meshes in the same Arashtad 3D Runtime scene.

3 Independent Meshes

Multiple Mesh Objects

Each <arashtad-mesh> creates an independent Babylon.js mesh in the same scene.

Meshes

box-mesh - Box

sphere-mesh - Sphere

cylinder-mesh - Cylinder

ground-mesh - Ground

Source

Multiple mesh elements can be declared directly inside the same runtime canvas. 

<arashtad-mesh
    type="Box"
    id="box-mesh"
    size="2"
    position="new BABYLON.Vector3(-3, 1, 0)">
</arashtad-mesh>

<arashtad-mesh
    type="Sphere"
    id="sphere-mesh"
    diameter="2"
    position="new BABYLON.Vector3(0, 1, 0)">
</arashtad-mesh>

<arashtad-mesh
    type="Cylinder"
    id="cylinder-mesh"
    height="2"
    diameter="2"
    tessellation="32"
    position="new BABYLON.Vector3(3, 1, 0)">
</arashtad-mesh>

<arashtad-mesh
    type="Ground"
    id="ground-mesh"
    width="10"
    height="5"
    position="new BABYLON.Vector3(0, 0, 0)">
</arashtad-mesh>
