IDs and References

Meshes with IDs are registered by the runtime and can be accessed through the runtime reference collection inside actions.

Runtime References

The left mesh is registered as parent.

The right mesh is registered as other.

The upper mesh is registered as child.

Actions access these registered meshes through refs.

Source

Complete source for this example. 

<arashtad-mesh
    id="parent"
    type="Box"
    size="2"
    position="new BABYLON.Vector3(-2.5, 0, 0)"
    OnPickTrigger="refs.other.rotation.y += 0.5">
</arashtad-mesh>

<arashtad-mesh
    id="other"
    type="Box"
    size="2"
    position="new BABYLON.Vector3(2.5, 0, 0)"
    OnPickTrigger="refs.parent.rotation.y += 0.5">
</arashtad-mesh>

<arashtad-mesh
    id="child"
    type="Box"
    size="1"
    position="new BABYLON.Vector3(0, 3, 0)"
    OnPickTrigger="refs.parent.rotation.y += 0.5">
</arashtad-mesh>
