Ground

Create a large horizontal ground surface using Babylon.js MeshBuilder through the Arashtad 3D Runtime.

Mesh: Ground

Ground Parameters

The Ground mesh creates a flat horizontal surface. Width and height determine the dimensions of the ground.

Configuration

width - Width of the ground surface.

height - Depth of the ground surface.

position - World-space position of the mesh.

Source

The complete runtime markup used to create the ground mesh. 

<canvas id="ground"
    clearColor="new BABYLON.Color4(0.008, 0.012, 0.018, 1)">

    <arashtad-runtime resize="engine.resize()"></arashtad-runtime>

    <arashtad-camera type="ArcRotateCamera" id="camera"
        args="Math.PI / 2, Math.PI / 3.2, 10, new BABYLON.Vector3(0, 0, 0)"
        minZ="0.1"
        maxZ="1000">
    </arashtad-camera>

    <arashtad-light type="HemisphericLight" id="light"
        args="new BABYLON.Vector3(0, 1, 0)"
        intensity="2">
    </arashtad-light>

    <arashtad-mesh type="Ground" id="ground-mesh"
        width="12"
        height="12"
        position="new BABYLON.Vector3(0, 0, 0)">
    </arashtad-mesh>

</canvas>
