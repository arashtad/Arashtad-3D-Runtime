Line-based mesh

Line-Based Mesh

65

Create a connected line mesh from a sequence of 3D points using Babylon.js MeshBuilder through the Arashtad 3D Runtime.

Mesh: Lines

Line Parameters

The Lines mesh connects the supplied points in sequence, producing a continuous line through the specified 3D coordinates.

Configuration

points - Ordered array of Babylon.js Vector3 points.

Vector3 - Defines each point's X, Y, and Z coordinates.

Source

The complete runtime markup used to create the line-based mesh. 

<canvas id="lines"
    clearColor="new BABYLON.Color4(0.008, 0.012, 0.018, 1)">

    <arashtad-runtime resize="engine.resize()"></arashtad-runtime>

    <arashtad-camera type="ArcRotateCamera" id="camera"
        args="Math.PI / 2, Math.PI / 2.6, 9, new BABYLON.Vector3(0, 0, 0)"
        minZ="0.1"
        maxZ="1000">
    </arashtad-camera>

    <arashtad-light type="HemisphericLight" id="light"
        args="new BABYLON.Vector3(0, 1, 0)"
        intensity="1.3">
    </arashtad-light>

    <arashtad-mesh type="Lines" id="lines-mesh"
        points="[
            new BABYLON.Vector3(-4, 0, 0),
            new BABYLON.Vector3(-2, 2, 0),
            new BABYLON.Vector3(0, 0, 0),
            new BABYLON.Vector3(2, -2, 0),
            new BABYLON.Vector3(4, 0, 0)
        ]">
    </arashtad-mesh>

</canvas>
