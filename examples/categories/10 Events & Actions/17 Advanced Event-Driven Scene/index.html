Example 138

Advanced Event Control Scene

Build an interactive control scene where pointer events coordinate multiple Babylon.js objects and modify the entire scene.

Events Actions Advanced
Hover a control to activate it.
Click any control to execute its command.
SYSTEM READY

What this demonstrates

Event Coordination

Individual objects can trigger transformations on other objects through the Babylon.js scene.

Scene Control

Runtime actions can manipulate meshes, materials, rotations, scaling, and the scene background.

Source

<arashtad-runtime resize="engine.resize()"></arashtad-runtime>

<arashtad-camera
    type="ArcRotateCamera"
    id="camera"
    args="Math.PI / 2, Math.PI / 2.5, 8, new BABYLON.Vector3(0, 1, 0)">
</arashtad-camera>

<arashtad-light
    type="HemisphericLight"
    id="light"
    args="new BABYLON.Vector3(0, 1, 0)"
    intensity="1.3">
</arashtad-light>

<arashtad-mesh
    type="Box"
    id="control"
    size="2"
    position="new BABYLON.Vector3(0, 1, 0)"
    isPickable="true"
    OnPickTrigger="
        mesh.rotation.y += Math.PI / 2;
        scene.clearColor = new BABYLON.Color4(
            Math.random() * 0.15,
            Math.random() * 0.2,
            Math.random() * 0.25,
            1
        );
    ">
</arashtad-mesh>
