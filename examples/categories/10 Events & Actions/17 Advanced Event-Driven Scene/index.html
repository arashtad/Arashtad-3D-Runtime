Advanced Event Control Scene

Build an interactive event-driven scene where multiple Babylon.js objects respond to pointer events and control other objects in the scene.

Events Actions Advanced
Hover a control to activate it.
Click any control to execute its command.
SYSTEM READY

What this demonstrates

Multiple runtime events can coordinate objects and trigger changes across the Babylon.js scene.

Event Coordination

Individual controls respond to pointer-over, pointer-out, and pick events while modifying their own state.

Scene Control

Actions can access other scene meshes and modify their rotation, scaling, materials, and the scene background.

Source

Runtime events can execute Babylon.js operations across multiple objects in the same scene. 

<arashtad-mesh
    type="Box"
    id="controlLeft"
    size="1.6"
    position="new BABYLON.Vector3(-2.3, 1, 0)"
    isPickable="true"
    OnPointerOverTrigger="
        if (!mesh.material) {
            mesh.material = new BABYLON.StandardMaterial('leftMaterial', scene);
        }
        mesh.material.diffuseColor = new BABYLON.Color3(0.1, 0.8, 0.6);
        document.getElementById('event-control-output').textContent =
            'LEFT CONTROL — ACTIVE';
    "
    OnPointerOutTrigger="
        if (!mesh.material) {
            mesh.material = new BABYLON.StandardMaterial('leftMaterial', scene);
        }
        mesh.material.diffuseColor = new BABYLON.Color3(0.2, 0.4, 0.35);
        document.getElementById('event-control-output').textContent =
            'SYSTEM READY';
    "
    OnPickTrigger="
        mesh.rotation.y += Math.PI / 2;
        mesh.scaling = new BABYLON.Vector3(
            0.8 + Math.random() * 1.2,
            0.8 + Math.random() * 1.2,
            0.8 + Math.random() * 1.2
        );
        scene.getMeshByName('controlCenter').rotation.x += Math.PI / 4;
        document.getElementById('event-control-output').textContent =
            'LEFT CONTROL — COMMAND EXECUTED';
    "
>
</arashtad-mesh>

<arashtad-mesh
    type="Box"
    id="controlCenter"
    size="2"
    position="new BABYLON.Vector3(0, 1.2, 0)"
    isPickable="true"
    OnPickTrigger="
        mesh.rotation.y += Math.PI / 2;
        mesh.scaling = new BABYLON.Vector3(
            0.8 + Math.random() * 1.2,
            0.8 + Math.random() * 1.2,
            0.8 + Math.random() * 1.2
        );
        scene.getMeshByName('controlLeft').rotation.z += Math.PI / 3;
        scene.getMeshByName('controlRight').rotation.z -= Math.PI / 3;
        scene.clearColor = new BABYLON.Color4(
            0.03 + Math.random() * 0.1,
            0.05 + Math.random() * 0.1,
            0.08 + Math.random() * 0.12,
            1
        );
        document.getElementById('event-control-output').textContent =
            'CORE CONTROL — GLOBAL COMMAND';
    "
>
</arashtad-mesh>
