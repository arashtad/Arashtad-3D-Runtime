Babylon Observable Event

Bind runtime actions to Babylon observables.

Events Babylon Observable

What this demonstrates

Bind a runtime action directly to a Babylon.js Observable.

Babylon Observable

The camera's onViewMatrixChangedObservable fires whenever its view matrix changes, such as when the camera is rotated or moved.

Runtime Action

Each observable notification executes the runtime action, which rotates the box slightly. Orbit the camera around the scene to see the observable in action.

Source

Observable attributes are resolved against the target object and subscribed through Babylon.js. 

<arashtad-camera
    type="ArcRotateCamera"
    id="camera"
    args="Math.PI / 2, Math.PI / 2.5, 7, new BABYLON.Vector3(0, 1, 0)"
    onViewMatrixChangedObservable="
        box.rotation.y += 0.002;
    "
>
</arashtad-camera>
