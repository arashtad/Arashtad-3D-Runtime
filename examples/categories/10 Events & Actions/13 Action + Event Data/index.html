Action + Event Data

Use event data inside an action.

Actions Events Runtime
Click the box to display event data.

What this demonstrates

Runtime action code can access event-related pointer information through the Babylon.js scene.

Picked Mesh

The action reads scene.meshUnderPointer to identify the mesh involved in the pointer event.

Pointer Position

The action reads scene.pointerX and scene.pointerY to access the current pointer coordinates.

Source

Event-related pointer information can be accessed from the current Babylon.js scene. 

<arashtad-mesh
    type="Box"
    id="box"
    size="2"
    position="new BABYLON.Vector3(0, 1, 0)"
    isPickable="true"
    OnPickTrigger="
        const pickedMesh = scene.meshUnderPointer;
        const pointerX = scene.pointerX;
        const pointerY = scene.pointerY;
        if (pickedMesh) {
            pickedMesh.rotation.y += Math.PI / 4;
            pickedMesh.scaling = new BABYLON.Vector3(1.2, 1.2, 1.2);
            document.getElementById('event-data-output').textContent =
                'Mesh: ' + pickedMesh.name +
                ' | Pointer X: ' + Math.round(pointerX) +
                ' | Pointer Y: ' + Math.round(pointerY);
        }
    "
>
</arashtad-mesh>
