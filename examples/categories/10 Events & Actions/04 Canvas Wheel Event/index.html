Canvas Wheel Event

Respond to a canvas wheel event.

Event Canvas Wheel

What this demonstrates

A native canvas wheel event handled through a runtime object.

Canvas-Wide Event

The on-wheel trigger responds when the mouse wheel is used over the canvas.

Target Object

Each wheel event changes the box's scaling.y value.

Source

A native wheel trigger is attached to the box and responds to wheel events anywhere on the canvas. 

<arashtad-mesh
    type="Box"
    id="box"
    size="2"
    position="new BABYLON.Vector3(0, 1, 0)"
    on-wheel="scaling.y += 0.1">
</arashtad-mesh>
