Immediate Action Execution

Execute an action immediately when it is processed.

Action Immediate

What this demonstrates

An action can execute immediately while the runtime processes its parent object.

Immediate Execution

The arashtad-action is nested inside the box and executes while the runtime processes the parent object.

Scene Result

The box is rotated immediately by Math.PI / 4 around its Y axis.

Source

The action is declared as an arashtad-action child of the target mesh. 

<arashtad-mesh
    type="Box"
    id="box"
    size="2"
    position="new BABYLON.Vector3(0, 1, 0)">

    <arashtad-action
        execute="box.rotation.y = Math.PI / 4">
    </arashtad-action>

</arashtad-mesh>
