Action Target

Execute an action against a specific target.

Actions Target References

What this demonstrates

Use the target attribute to resolve a specific runtime object before executing an action.

Target Resolution

The action explicitly targets the object registered as box.

Execute

The action rotates the targeted box by 45 degrees when the action is executed.

Source

The target attribute identifies the object that receives the action. 

<arashtad-action
    target="box"
    execute="box.rotation.y += Math.PI / 4"
>
</arashtad-action>
