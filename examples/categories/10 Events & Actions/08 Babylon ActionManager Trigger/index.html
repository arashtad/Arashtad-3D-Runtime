Babylon ActionManager Trigger

Use Babylon ActionManager triggers.

Events ActionManager Babylon

What this demonstrates

Babylon ActionManager triggers provide object-level event handling through Babylon.js.

OnPickTrigger

Clicking the box activates its Babylon ActionManager and executes the associated runtime action.

OnPointerOutTrigger

Moving the pointer away from the picked mesh restores its original scale. Both triggers operate on the mesh itself.

Source

Babylon ActionManager trigger attributes are mapped to Babylon trigger constants and executed through the runtime action system. 

<arashtad-mesh
    type="Box"
    id="box"
    size="2"
    position="new BABYLON.Vector3(0, 1, 0)"
    isPickable="true"
    OnPickTrigger="
        scaling = new BABYLON.Vector3(1.3, 1.3, 1.3);
    "
    OnPointerOutTrigger="
        scaling = new BABYLON.Vector3(1, 1, 1);
    "
>
</arashtad-mesh>
