Pointer Observable Event

Bind to a Babylon pointer observable.

Event Babylon Pointer

What this demonstrates

A Babylon pointer observable can be bound directly through a runtime attribute.

Pointer Observable

The on-pointerdown attribute binds to the object's Babylon pointer observable.

Object-Level Event

Unlike native canvas events, the observable is attached to the Babylon object itself.

Source

The pointer observable is declared directly on the mesh. 

<arashtad-mesh
    type="Box"
    id="box"
    size="2"
    position="new BABYLON.Vector3(0, 1, 0)"
    on-pointerdown="scaling = new BABYLON.Vector3(1.3, 1.3, 1.3)">
</arashtad-mesh>
