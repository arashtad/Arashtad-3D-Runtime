Multiple Events

Combine multiple runtime events.

Events Multiple Runtime
Move the pointer over the box or click it to trigger different events.

What this demonstrates

A single mesh can respond to multiple runtime events, with each event executing its own action.

Pointer Events

Move the pointer over and away from the box to trigger OnPointerOverTrigger and OnPointerOutTrigger.

Pick Event

Click the box to trigger OnPickTrigger and rotate the mesh.

Source

Multiple event attributes can be attached to the same runtime mesh. 

<arashtad-mesh
    type="Box"
    id="box"
    size="2"
    position="new BABYLON.Vector3(0, 1, 0)"
    isPickable="true"
    OnPickTrigger="
        box.rotation.y += Math.PI / 4;
        document.getElementById('multiple-events-output').textContent = 'Event: Box picked';
    "
    OnPointerOverTrigger="
        box.scaling = new BABYLON.Vector3(1.15, 1.15, 1.15);
        document.getElementById('multiple-events-output').textContent = 'Event: Pointer over';
    "
    OnPointerOutTrigger="
        box.scaling = new BABYLON.Vector3(1, 1, 1);
        document.getElementById('multiple-events-output').textContent = 'Event: Pointer out';
    "
>
</arashtad-mesh>
