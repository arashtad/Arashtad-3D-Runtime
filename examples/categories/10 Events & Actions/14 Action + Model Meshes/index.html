Action + Model Meshes

Use imported model meshes inside actions.

Actions Models Runtime
Click the model mesh to control it from the action.

What this demonstrates

Runtime actions can retrieve and manipulate meshes belonging to an imported Babylon.js model.

Model Mesh

Imported models are represented by Babylon.js mesh objects that can be accessed from the scene.

Mesh Access

The action uses scene.getMeshByName() to retrieve a specific model mesh and modify it.

Source

A runtime action can retrieve a model mesh from the Babylon.js scene and use its normal mesh properties and methods. 

<arashtad-mesh
    type="Box"
    id="model-part"
    size="2"
    position="new BABYLON.Vector3(0, 1, 0)"
    isPickable="true"
    OnPickTrigger="
        const mesh = scene.getMeshByName('model-part');
        if (mesh) {
            mesh.rotation.y += Math.PI / 4;
            mesh.scaling = new BABYLON.Vector3(1.2, 1.2, 1.2);
        }
    "
>
</arashtad-mesh>
