Action + Scene

Access the scene from runtime action code.

Actions Scene Runtime

What this demonstrates

Runtime action code receives the current Babylon.js scene and can use it directly.

Scene Access

The action uses the scene reference supplied by the runtime action system.

Scene Property

Pick the box to modify the Babylon.js scene's clearColor property directly.

Source

The runtime action can access the current scene through the scene variable. 

<arashtad-mesh
    type="Box"
    id="box"
    size="2"
    position="new BABYLON.Vector3(0, 1, 0)"
    isPickable="true"
    OnPickTrigger="
        scene.clearColor = new BABYLON.Color4(0.1, 0.3, 0.25, 1);
    "
>
</arashtad-mesh>
