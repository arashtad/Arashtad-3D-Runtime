Action + BABYLON API

Use the Babylon.js API inside an action.

Actions Babylon.js Runtime

What this demonstrates

Runtime action code can use the Babylon.js API directly through the global BABYLON namespace.

BABYLON API

The action creates a BABYLON.Vector3 value directly inside the action code.

Mesh Control

Pick the box to use Babylon.js rotation and scaling APIs directly from the action.

Source

Runtime actions can use Babylon.js classes and methods through the BABYLON namespace. 

<arashtad-mesh
    type="Box"
    id="box"
    size="2"
    position="new BABYLON.Vector3(0, 1, 0)"
    isPickable="true"
    OnPickTrigger="
        rotation.y += Math.PI / 4;
        scaling = new BABYLON.Vector3(1.2, 1.2, 1.2);
    "
>
</arashtad-mesh>
