Basic Action

Execute a basic runtime action.

Action Runtime

What this demonstrates

A basic runtime action executed directly from a mesh trigger.

Interactive Mesh

The box is configured as pickable and responds to OnPickTrigger.

Runtime Action

Each click rotates the box by Math.PI / 4 around its Y axis.

Source

The action is declared directly on the mesh using the runtime's native pick trigger. 

<arashtad-mesh
    type="Box"
    id="box"
    size="2"
    position="new BABYLON.Vector3(0, 1, 0)"
    isPickable="true"
    OnPickTrigger="
        box.rotation.y += Math.PI / 4;
    ">
</arashtad-mesh>
