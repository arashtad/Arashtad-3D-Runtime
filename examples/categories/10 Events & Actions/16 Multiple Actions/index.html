Multiple Actions

Combine multiple runtime actions.

Actions Multiple Runtime
Click the box for a random scale, rotation and material color.

What this demonstrates

A single runtime action can execute multiple Babylon.js operations in sequence.

Multiple Actions

Each click rotates the box and assigns a new random scale.

Material Change

The same action creates a new material with a random diffuse color.

Source

Multiple Babylon.js operations can be combined inside a single runtime action. 

<arashtad-mesh
    type="Box"
    id="box"
    size="2"
    position="new BABYLON.Vector3(0, 1, 0)"
    isPickable="true"
    OnPickTrigger="
        box.rotation.y += Math.PI / 4;

        const scale = 0.5 + Math.random() * 2.5;
        box.scaling = new BABYLON.Vector3(scale, scale, scale);

        const material = new BABYLON.StandardMaterial('action-material-' + Date.now(), scene);
        material.diffuseColor = new BABYLON.Color3(
            Math.random(),
            Math.random(),
            Math.random()
        );
        material.specularColor = new BABYLON.Color3(0.8, 0.8, 0.8);
        box.material = material;

        document.getElementById('multiple-actions-output').textContent =
            'Actions: Rotation + Random Scale + Material Color';
    "
>
</arashtad-mesh>
