Other Native Canvas Events

Use other native canvas DOM events.

Event Canvas DOM

What this demonstrates

Native DOM events other than click and wheel can be handled by the runtime.

Double Click

The on-dblclick event rotates the box by Math.PI / 4.

Mouse Enter / Leave

The on-mouseenter and on-mouseleave events change the box scale while the pointer enters or leaves the canvas.

Source

Native DOM event names are written after the on- prefix. 

<arashtad-mesh
    type="Box"
    id="box"
    size="2"
    position="new BABYLON.Vector3(0, 1, 0)"
    on-dblclick="rotation.y += Math.PI / 4"
    on-mouseenter="scaling = new BABYLON.Vector3(1.25, 1.25, 1.25)"
    on-mouseleave="scaling = new BABYLON.Vector3(1, 1, 1)">
</arashtad-mesh>
