Linear and Angular Velocity

Launch a box with initial linear and angular velocity using Arashtad 3D Runtime and Havok physics.

Physics Velocity Havok
linear="(5, 0, 0)" · angular="(0, 2, 0)"

What this demonstrates

Give a body an initial push and spin at the moment it is created by using a nested <arashtad-velocity> element.

Linear Velocity

linear sets the initial translation vector. The box moves along X immediately and falls under gravity while it travels.

Angular Velocity

angular sets the initial rotation vector. Here the box spins around its Y axis while it moves, so translation and rotation happen together.

Source

Nest <arashtad-velocity> inside <arashtad-physics> to set initial velocities on the body. 

<arashtad-material
    id="brown"
    type="StandardMaterial"
    diffuseColor="new BABYLON.Color3(0.7, 0.5, 0.3)"
>
</arashtad-material>

<arashtad-mesh
    id="box"
    type="Box"
    size="1"
    position="new BABYLON.Vector3(0, 5, 0)"
    material="brown"
>
    <arashtad-physics
        type="BOX"
        mass="1"
        restitution="0.3"
        friction="0.5"
    >
        <arashtad-velocity
            linear="new BABYLON.Vector3(5, 0, 0)"
            angular="new BABYLON.Vector3(0, 2, 0)"
        ></arashtad-velocity>
    </arashtad-physics>
</arashtad-mesh>
