Elevator Platform

Move a kinematic platform up and down to carry a dynamic box using Arashtad 3D Runtime and Havok physics.

Physics Kinematic Animation
kinematic platform oscillates between y=1 and y=6 · box rides it

What this demonstrates

A kinematic body driven by its transform carries a dynamic body along with it through moving contact.

Kinematic Motion

The platform's nested <arashtad-body type="KINEMATIC"> makes it ignore gravity. Its Y position is updated each frame by an observable, so Havok sees a moving collider.

Carrying Dynamic Bodies

When the platform rises, it pushes the box up. When it descends, the box falls and catches up again. High friction between them keeps the box from sliding off.

Source

Give the platform a kinematic body, then drive its position.y from a per-frame observable. 

<arashtad-material
    id="blue"
    type="StandardMaterial"
    diffuseColor="new BABYLON.Color3(0.3, 0.5, 0.9)"
>
</arashtad-material>

<arashtad-material
    id="green"
    type="StandardMaterial"
    diffuseColor="new BABYLON.Color3(0.3, 0.5, 0.3)"
>
</arashtad-material>

<arashtad-mesh
    id="platform"
    type="Box"
    width="4"
    height="0.4"
    depth="3"
    position="new BABYLON.Vector3(0, 1, 0)"
    material="blue"
>
    <arashtad-physics
        type="BOX"
        mass="0"
        friction="0.9"
    >
        <arashtad-body type="KINEMATIC"></arashtad-body>
    </arashtad-physics>

    <arashtad-action
        execute="
            let t = 0;
            scene.onBeforeRenderObservable.add(() => {
                t += 0.016;
                target.position.y = 1 + Math.sin(t) * 2.5;
            });
        "
    >
    </arashtad-action>
</arashtad-mesh>

<arashtad-mesh
    id="box"
    type="Box"
    size="1"
    position="new BABYLON.Vector3(0, 3.5, 0)"
    material="green"
>
    <arashtad-physics
        type="BOX"
        mass="1"
        restitution="0.1"
        friction="0.9"
        linearDamping="0.1"
        angularDamping="0.1"
    ></arashtad-physics>
</arashtad-mesh>
