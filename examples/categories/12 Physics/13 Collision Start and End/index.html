Collision Start and End

Handle both collision started and collision ended events using Arashtad 3D Runtime and Havok physics.

Physics Collision Havok
Open the console to see "STARTED" and "ENDED" events for each collision pair.

What this demonstrates

Use both on-collide and on-end to capture the full lifecycle of a collision contact.

Collision Started

on-collide fires on every collision update. Filtering by event.type === 'COLLISION_STARTED' reduces it to the moment two bodies first touch.

Collision Ended

on-end is a dedicated handler that maps directly to Havok's collision-ended observable, so no type filtering is required on that side.

Source

Provide both on-collide and on-end attributes on the same <arashtad-collision> element. 

<arashtad-mesh
    id="box1"
    type="Box"
    size="1"
    position="new BABYLON.Vector3(0, 8, 0)"
    material="green"
>
    <arashtad-physics
        type="BOX"
        mass="1"
        restitution="0.8"
    >
        <arashtad-collision
            on-collide="
                if (event.type === 'COLLISION_STARTED') {
                    console.log('STARTED', event);
                }
            "
            on-end="
                console.log('ENDED', event);
            "
        ></arashtad-collision>
    </arashtad-physics>
</arashtad-mesh>
