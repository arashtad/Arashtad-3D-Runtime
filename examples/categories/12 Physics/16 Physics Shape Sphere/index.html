Physics Shape Sphere

Use a SPHERE physics shape for rolling balls with Arashtad 3D Runtime and Havok physics.

Physics Shape Havok
type="SPHERE" · two balls rolling with initial linear velocity

What this demonstrates

Give a sphere-shaped mesh a matching SPHERE physics shape so it rolls smoothly along a flat surface.

SPHERE Shape

The type attribute on <arashtad-physics> maps to a PhysicsShapeType. Using SPHERE on a sphere mesh gives Havok an exact analytic collider that rolls without faceting.

Rolling Motion

Each ball starts with an initial <arashtad-velocity> on the X axis. Friction between the sphere and the ground converts the sliding motion into rotation, so the balls roll forward.

Source

Match the mesh type with the physics shape type and give the balls some horizontal velocity to see them roll. 

<arashtad-material
    id="green"
    type="StandardMaterial"
    diffuseColor="new BABYLON.Color3(0.3, 0.5, 0.3)"
>
</arashtad-material>

<arashtad-material
    id="orange"
    type="StandardMaterial"
    diffuseColor="new BABYLON.Color3(1.0, 0.4, 0.3)"
>
</arashtad-material>

<arashtad-material
    id="brown"
    type="StandardMaterial"
    diffuseColor="new BABYLON.Color3(0.7, 0.5, 0.3)"
>
</arashtad-material>

<arashtad-mesh
    id="ground"
    type="Ground"
    width="14"
    height="14"
    material="brown"
>
    <arashtad-physics
        type="BOX"
        mass="0"
        friction="0.8"
    ></arashtad-physics>
</arashtad-mesh>

<arashtad-mesh
    id="ball1"
    type="Sphere"
    diameter="1"
    segments="24"
    position="new BABYLON.Vector3(-3, 3, 0)"
    material="green"
>
    <arashtad-physics
        type="SPHERE"
        mass="1"
        restitution="0.4"
        friction="0.4"
    >
        <arashtad-velocity
            linear="new BABYLON.Vector3(4, 0, 0)"
        ></arashtad-velocity>
    </arashtad-physics>
</arashtad-mesh>

<arashtad-mesh
    id="ball2"
    type="Sphere"
    diameter="1.4"
    segments="24"
    position="new BABYLON.Vector3(-3, 5, 2)"
    material="orange"
>
    <arashtad-physics
        type="SPHERE"
        mass="2"
        restitution="0.3"
        friction="0.4"
    >
        <arashtad-velocity
            linear="new BABYLON.Vector3(3.5, 0, 0)"
        ></arashtad-velocity>
    </arashtad-physics>
</arashtad-mesh>
