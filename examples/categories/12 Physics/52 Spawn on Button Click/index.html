Spawn on Button Click

Add a button that spawns a new dynamic sphere on each press using Arashtad 3D Runtime and Havok physics.

Physics GUI Action
0 spheres spawned
Click "Spawn sphere" to add a new dynamic body above the ground

What this demonstrates

Create dynamic bodies on demand from a plain HTML button. Each sphere is fully simulated by Havok from the moment it appears.

Runtime Spawning

Each press of the button creates a fresh Sphere mesh via MeshBuilder.CreateSphere, assigns one of four pre-registered materials, and wraps it in a PhysicsAggregate with a random restitution.

Cleanup

Spawned meshes are tracked in a list so a second button can dispose them along with their physics bodies. That keeps the scene from filling up during long runs.

Source

Two plain HTML buttons drive sphere creation and cleanup through shared helpers. 

<button type="button" id="spawn-button">Spawn sphere</button>
<button type="button" id="clear-button">Clear all</button>

<arashtad-material
    id="green"
    type="StandardMaterial"
    diffuseColor="new BABYLON.Color3(0.3, 0.5, 0.3)"
>
</arashtad-material>
