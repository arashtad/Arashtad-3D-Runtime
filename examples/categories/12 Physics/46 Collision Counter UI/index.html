Collision Counter UI

Count collisions between a box and the ground using a GUI text with Arashtad 3D Runtime and Havok physics.

Physics Collision GUI
Collision count · 0 · click the small cube to add more impacts

What this demonstrates

Keep a running count of collisions and mirror it into a visible counter. Each impact updates a piece of the host page in real time.

Counter State

The collision callback stores its count on window.__collisions. Each new impact increments that value and pushes it into a DOM span with textContent.

Driving More Collisions

Clicking the small cube on the right applies an upward impulse to the main box, so it lifts off, falls back, and triggers another collision. Repeated clicks grow the count visibly.

Source

Increment a counter inside the collision callback and write it into a DOM element on the page. 

<arashtad-mesh
    id="box"
    type="Box"
    size="1.2"
    position="new BABYLON.Vector3(0, 6, 0)"
    material="green"
>
    <arashtad-physics
        type="BOX"
        mass="1"
        restitution="0.5"
        friction="0.5"
        startAsleep="false"
    >
        <arashtad-collision
            type="started"
            on-collide="
                window.__collisions = (window.__collisions || 0) + 1;

                const display = document.getElementById('collision-count');
                if (display) {
                    display.textContent = window.__collisions;
                }
            "
        ></arashtad-collision>
    </arashtad-physics>
</arashtad-mesh>

<arashtad-mesh
    id="bumper"
    type="Box"
    width="0.6"
    height="0.6"
    depth="0.6"
    position="new BABYLON.Vector3(3, 0.4, 0)"
    material="green"
    onPickTrigger="
        const box = refs['box'];
        const aggregate = box?.metadata?.physicsAggregate;

        if (aggregate?.body) {
            aggregate.body.applyImpulse(
                new BABYLON.Vector3(0, 8, 0),
                box.getAbsolutePosition()
            );
        }
    "
>
    <arashtad-physics
        type="BOX"
        mass="1"
        restitution="0.2"
        friction="0.5"
    ></arashtad-physics>
</arashtad-mesh>
