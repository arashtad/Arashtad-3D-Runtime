Shoot a Cannonball

Fire a sphere with linear velocity along the camera forward vector using Arashtad 3D Runtime and Havok physics.

Physics Velocity Camera
Click the ground → fire a cannonball along the camera forward vector

What this demonstrates

Spawn a dynamic sphere at the camera origin, give it a linear velocity along the camera forward vector, and let Havok carry it through the scene.

Camera Forward Vector

scene.activeCamera.getForwardRay().direction returns the unit vector the camera is currently looking down. That same direction becomes the cannonball's launch axis.

Linear Velocity on Spawn

Instead of an impulse, the sphere is given a linear velocity directly via setLinearVelocity. Because the ball has mass, the velocity translates into real kinetic energy under Havok.

Source

Read the camera forward vector, spawn a sphere, and set its initial linear velocity along that direction. 

<arashtad-mesh
    id="ground"
    type="Ground"
    width="20"
    height="20"
    material="brown"
    onPickTrigger="
        const forward = scene.activeCamera.getForwardRay().direction;
        const origin = scene.activeCamera.position;

        const ball = BABYLON.MeshBuilder.CreateSphere(
            'ball_' + Date.now(),
            { diameter: 0.6, segments: 24 },
            scene
        );

        ball.position = origin.add(forward.scale(1.5));
        ball.material = refs['orange'];

        const aggregate = new BABYLON.PhysicsAggregate(
            ball,
            BABYLON.PhysicsShapeType.SPHERE,
            { mass: 2, restitution: 0.3, friction: 0.4 },
            scene
        );

        aggregate.body.setLinearVelocity(
            forward.scale(25)
        );
    "
>
    <arashtad-physics
        type="BOX"
        mass="0"
        friction="0.6"
    ></arashtad-physics>
</arashtad-mesh>
