Collision Event Fields

Inspect type, collider, point, normal, and impulse on collision using Arashtad 3D Runtime and Havok physics.

Physics Collision Havok
Open the console to inspect individual event fields on each collision.

What this demonstrates

Read individual fields from the Havok collision event object instead of logging the whole thing at once.

Event Fields

event.type is the collision phase, event.collider and event.collidedAgainst are the two bodies, event.point and event.normal describe the contact, and event.impulse measures the impact strength.

Per-Body Inspection

Both dynamic boxes log their own collisions, so you can compare how the same event fields look from each body's perspective.

Source

Read individual fields from event inside the on-collide callback. 

<arashtad-mesh
    id="box1"
    type="Box"
    size="1"
    position="new BABYLON.Vector3(0, 8, 0)"
    material="green"
>
    <arashtad-physics
        type="BOX"
        mass="1"
        restitution="0.8"
    >
        <arashtad-collision
            on-collide="
                console.log('COLLISION');
                console.log('type:', event.type);
                console.log('collider:', event.collider);
                console.log('against:', event.collidedAgainst);
                console.log('point:', event.point);
                console.log('normal:', event.normal);
                console.log('impulse:', event.impulse);
            "
        ></arashtad-collision>
    </arashtad-physics>
</arashtad-mesh>
