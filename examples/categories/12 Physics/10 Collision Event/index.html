Collision Event

Log collision events when a box hits the ground using Arashtad 3D Runtime and Havok physics.

Physics Collision Havok
Open the console to see "COLLISION:" events when the box hits the ground.

What this demonstrates

Subscribe to Havok collision events on a specific body with the nested <arashtad-collision> element.

On-Collide Callback

The on-collide attribute contains JavaScript that runs every time the body reports a collision. Inside the callback, event holds the Havok collision data.

Enabling Callbacks

The runtime automatically enables collision callbacks on the body when an on-collide handler is present, so no extra flags are needed in the markup.

Source

Nest <arashtad-collision> inside <arashtad-physics> and provide an on-collide expression. 

<arashtad-material
    id="green"
    type="StandardMaterial"
    diffuseColor="new BABYLON.Color3(0.3, 0.5, 0.3)"
>
</arashtad-material>

<arashtad-material
    id="brown"
    type="StandardMaterial"
    diffuseColor="new BABYLON.Color3(0.7, 0.5, 0.3)"
>
</arashtad-material>

<arashtad-mesh
    id="box"
    type="Box"
    size="1"
    position="new BABYLON.Vector3(0, 5, 0)"
    material="green"
>
    <arashtad-physics
        type="BOX"
        mass="1"
        restitution="0.3"
        friction="0.5"
    >
        <arashtad-collision
            on-collide="console.log('COLLISION:', event)"
        ></arashtad-collision>
    </arashtad-physics>
</arashtad-mesh>

<arashtad-mesh
    id="ground"
    type="Ground"
    width="10"
    height="10"
    material="brown"
>
    <arashtad-physics
        type="BOX"
        mass="0"
        restitution="0.2"
        friction="0.8"
    ></arashtad-physics>
</arashtad-mesh>
