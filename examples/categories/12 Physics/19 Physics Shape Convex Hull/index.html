Physics Shape Convex Hull

Use a CONVEX_HULL shape for approximate mesh collision with Arashtad 3D Runtime and Havok physics.

Physics Shape Havok
type="CONVEX_HULL" · two polyhedra with approximate mesh collision

What this demonstrates

Give a complex mesh a CONVEX_HULL physics shape so Havok wraps the geometry in a convex collider.

CONVEX_HULL Shape

A convex hull is the smallest convex polyhedron that contains all of the mesh's vertices. It gives an approximate but efficient collider for shapes that are already convex or nearly convex.

Approximate Collision

Unlike a MESH shape which uses the exact geometry, a CONVEX_HULL ignores interior details and concave features. That makes it much cheaper to simulate while staying visually close for convex meshes.

Source

Set type="CONVEX_HULL" on the physics element when the mesh is convex or nearly convex.

<arashtad-mesh
    id="ground"
    type="Ground"
    width="14"
    height="14"
    material="brown"
>
    <arashtad-physics
        type="BOX"
        mass="0"
        friction="0.8"
    ></arashtad-physics>
</arashtad-mesh>

<arashtad-mesh
    id="poly1"
    type="Polyhedron"
    type_="1"
    size="1.5"

>
    <arashtad-physics
        type="CONVEX_HULL"
        mass="1"
        restitution="0.3"
        friction="0.5"
    ></arashtad-physics>
</arashtad-mesh>
