Havok Physics Initialization

Initialize Havok through the runtime and see the scene physics enabled on the first physics element.

Physics Havok Initialization
Click the box → console shows scene.isPhysicsEnabled()

What this demonstrates

Havok is loaded lazily by the runtime the first time any <arashtad-physics> element is processed.

Lazy Initialization

The runtime checks scene.isPhysicsEnabled() before creating a physics aggregate. If physics is not yet enabled, it loads Havok, creates a HavokPlugin, and enables physics with default gravity.

Verifying It On Screen

The box carries an onPointerDownObservable handler that logs scene.isPhysicsEnabled(). Clicking the box confirms the engine is active without any manual setup code.

Source

The ground also carries a <arashtad-physics> element, but the box demonstrates Havok being enabled the moment the first physics body is processed. 

<arashtad-material
    id="green"
    type="StandardMaterial"
    diffuseColor="new BABYLON.Color3(0.3, 0.5, 0.3)"
>
</arashtad-material>

<arashtad-material
    id="brown"
    type="StandardMaterial"
    diffuseColor="new BABYLON.Color3(0.7, 0.5, 0.3)"
>
</arashtad-material>

<arashtad-mesh
    id="ground"
    type="Ground"
    width="10"
    height="10"
    material="brown"
>
    <arashtad-physics
        type="BOX"
        mass="0"
        friction="0.8"
    ></arashtad-physics>
</arashtad-mesh>

<arashtad-mesh
    id="box"
    type="Box"
    size="1"
    position="new BABYLON.Vector3(0, 5, 0)"
    material="green"
    onPointerDownObservable="
        console.log('isPhysicsEnabled:', scene.isPhysicsEnabled());
    "
>
    <arashtad-physics
        type="BOX"
        mass="1"
        restitution="0.3"
        friction="0.5"
    ></arashtad-physics>
</arashtad-mesh>
