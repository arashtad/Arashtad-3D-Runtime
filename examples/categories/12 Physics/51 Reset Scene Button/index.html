Reset Scene Button

Add a button that resets all dynamic bodies to their start transforms using Arashtad 3D Runtime and Havok physics.

Physics GUI Action
ready · 4 dynamic bodies
Click "Reset scene" to return every body to its start transform

What this demonstrates

Snapshot each body's start state, then recreate its physics body on reset. Destroying and recreating is the most reliable way to teleport a running dynamic body in Babylon's Havok plugin.

Full Snapshot

Each body's position, rotation, physics shape type, and physics options are captured at scene start. That's enough to rebuild the body identically.

Recreate on Reset

On reset, the old body is disposed and a new PhysicsAggregate is created at the snapshot transform with the original options. The body exists fresh in Havok at the exact start position.

Source

A shared reset helper disposes and recreates each body at its snapshot transform. 

<arashtad-mesh
    id="greenbox"
    type="Box"
    size="1"
    position="new BABYLON.Vector3(-2, 6, -1)"
    material="green"
>
    <arashtad-physics
        type="BOX"
        mass="1"
        restitution="0.5"
        friction="0.5"
        startAsleep="false"
    ></arashtad-physics>
</arashtad-mesh>

<!-- orangebox · bluesphere · yellowcylinder -->

<button type="button" id="reset-button">Reset scene</button>
