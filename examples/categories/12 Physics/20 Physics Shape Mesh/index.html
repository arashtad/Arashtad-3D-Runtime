Physics Shape Mesh

Use a MESH shape for exact mesh collision with Arashtad 3D Runtime and Havok physics.

Physics Shape Havok
type="MESH" · torus knot collider follows the exact geometry

What this demonstrates

Give a non-convex mesh an exact MESH physics shape so Havok resolves contacts against the real geometry.

MESH Shape

A MESH collider is built directly from the mesh's triangles. It can represent concave features that CONVEX_HULL cannot, at the cost of more simulation work per contact.

Torus Knot

A torus knot is a canonical non-convex shape, so it is a natural fit for demonstrating what MESH shape adds over CONVEX_HULL. The collider follows the tube and the hole exactly.

Source

Set type="MESH" when the mesh is non-convex or when you need exact triangle-level collision. 

<arashtad-material
    id="green"
    type="StandardMaterial"
    diffuseColor="new BABYLON.Color3(0.3, 0.5, 0.3)"
>
</arashtad-material>

<arashtad-material
    id="brown"
    type="StandardMaterial"
    diffuseColor="new BABYLON.Color3(0.7, 0.5, 0.3)"
>
</arashtad-material>

<arashtad-mesh
    id="ground"
    type="Ground"
    width="14"
    height="14"
    material="brown"
>
    <arashtad-physics
        type="BOX"
        mass="0"
        friction="0.8"
    ></arashtad-physics>
</arashtad-mesh>

<arashtad-mesh
    id="torusknot"
    type="TorusKnot"
    radius="0.7"
    tube="0.22"
    radialSegments="96"
    tubularSegments="24"
    position="new BABYLON.Vector3(0, 5, 0)"
    material="green"
>
    <arashtad-physics
        type="MESH"
        mass="1"
        restitution="0.4"
        friction="0.5"
    ></arashtad-physics>
</arashtad-mesh>
