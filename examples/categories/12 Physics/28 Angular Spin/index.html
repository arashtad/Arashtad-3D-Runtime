Angular Spin

Apply pure angular velocity and watch a box spin in place with Arashtad 3D Runtime and Havok physics.

Physics Velocity Angular
same mass, damping, friction · angular Y = 3 vs 12

What this demonstrates

Give a body pure angular velocity with no linear component and watch it spin in place on the ground.

Angular Only

The angular attribute of <arashtad-velocity> sets the initial rotation rate. With no linear attribute, the body spins without translating.

Damping Slows It

A high angularDamping value causes the spin to slow over time, so both boxes eventually settle. The faster box stays spinning visibly longer than the slower one.

Source

Set only the angular attribute on <arashtad-velocity> to make a body spin in place. 

<arashtad-material
    id="green"
    type="StandardMaterial"
    diffuseColor="new BABYLON.Color3(0.3, 0.5, 0.3)"
>
</arashtad-material>

<arashtad-material
    id="orange"
    type="StandardMaterial"
    diffuseColor="new BABYLON.Color3(1.0, 0.4, 0.3)"
>
</arashtad-material>

<arashtad-mesh
    id="slowspin"
    type="Box"
    size="1.2"
    position="new BABYLON.Vector3(-2, 2, 0)"
    material="green"
>
    <arashtad-physics
        type="BOX"
        mass="1"
        restitution="0.2"
        friction="0.4"
        angularDamping="1.5"
    >
        <arashtad-velocity
            angular="new BABYLON.Vector3(0, 3, 0)"
        ></arashtad-velocity>
    </arashtad-physics>
</arashtad-mesh>

<arashtad-mesh
    id="fastspin"
    type="Box"
    size="1.2"
    position="new BABYLON.Vector3(2, 2, 0)"
    material="orange"
>
    <arashtad-physics
        type="BOX"
        mass="1"
        restitution="0.2"
        friction="0.4"
        angularDamping="1.5"
    >
        <arashtad-velocity
            angular="new BABYLON.Vector3(0, 12, 0)"
        ></arashtad-velocity>
    </arashtad-physics>
</arashtad-mesh>
