Multiple Dynamic Bodies

Collide two dynamic boxes above a static ground with restitution using Arashtad 3D Runtime and Havok physics.

Physics Collision Multiple
box1 & box2 · mass="1" · restitution="0.5" · static ground

What this demonstrates

Multiple dynamic bodies interacting with each other and with a shared static collider.

Body-to-Body Collision

Two dynamic bodies fall at slightly offset positions. When they meet, Havok resolves the contact and each body reacts based on its mass, restitution, and friction.

Shared Ground

A single static ground collides with both dynamic bodies, demonstrating that one static body can serve many dynamic bodies in the same scene.

Source

Add more dynamic bodies by repeating <arashtad-mesh> with an <arashtad-physics> child. 

<arashtad-material
    id="green"
    type="StandardMaterial"
    diffuseColor="new BABYLON.Color3(0.3, 0.5, 0.3)"
>
</arashtad-material>

<arashtad-material
    id="orange"
    type="StandardMaterial"
    diffuseColor="new BABYLON.Color3(1.0, 0.4, 0.3)"
>
</arashtad-material>

<arashtad-material
    id="brown"
    type="StandardMaterial"
    diffuseColor="new BABYLON.Color3(0.7, 0.5, 0.3)"
>
</arashtad-material>

<arashtad-mesh
    id="box1"
    type="Box"
    size="1"
    position="new BABYLON.Vector3(0, 5, 0)"
    material="green"
>
    <arashtad-physics
        type="BOX"
        mass="1"
        restitution="0.5"
        friction="0.5"
    ></arashtad-physics>
</arashtad-mesh>

<arashtad-mesh
    id="box2"
    type="Box"
    size="1"
    position="new BABYLON.Vector3(0.3, 8, 0)"
    material="orange"
>
    <arashtad-physics
        type="BOX"
        mass="1"
        restitution="0.5"
        friction="0.5"
    ></arashtad-physics>
</arashtad-mesh>

<arashtad-mesh
    id="ground"
    type="Ground"
    width="10"
    height="10"
    material="brown"
>
    <arashtad-physics
        type="BOX"
        mass="0"
        friction="0.8"
    ></arashtad-physics>
</arashtad-mesh>
