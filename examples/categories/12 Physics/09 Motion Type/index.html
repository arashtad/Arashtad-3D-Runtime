Motion Type

Set the motion type of a physics body explicitly using Arashtad 3D Runtime and Havok physics.

Physics Body Motion
motionType="DYNAMIC" · linear="(3, 0, 0)" · angular="(0, 2, 0)"

What this demonstrates

Explicitly set the Havok motion type on a body with the <arashtad-body> element instead of relying on the mass-derived default.

Motion Type

DYNAMIC bodies respond to gravity, forces, impulses, and collisions. Havok also supports STATIC and KINEMATIC, which change how a body reacts to the simulation.

Combined with Velocity

The nested <arashtad-velocity> gives the body an initial linear and angular velocity, so once the motion type is applied the box moves and spins under simulation.

Source

Set the motion type with a nested <arashtad-body> element inside <arashtad-physics>. 

<arashtad-material
    id="green"
    type="StandardMaterial"
    diffuseColor="new BABYLON.Color3(0.3, 0.5, 0.3)"
>
</arashtad-material>

<arashtad-mesh
    id="box"
    type="Box"
    size="1"
    position="new BABYLON.Vector3(0, 5, -10)"
    material="green"
>
    <arashtad-physics
        type="BOX"
        mass="1"
        restitution="0.3"
        friction="0.5"
    >
        <arashtad-velocity
            linear="new BABYLON.Vector3(3, 0, 0)"
            angular="new BABYLON.Vector3(0, 2, 0)"
        ></arashtad-velocity>

        <arashtad-body type="DYNAMIC"></arashtad-body>
    </arashtad-physics>
</arashtad-mesh>
