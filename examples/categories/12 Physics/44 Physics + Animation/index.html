Physics + Animation

Play a model animation when its physics body starts colliding using Arashtad 3D Runtime and Havok physics.

Waiting for the model to hit the ground...
GLB model with physics · collision triggers the selected animation

What this demonstrates

Combine three runtime systems: a loaded GLB model, its physics bodies, and its animation groups. A collision on the body becomes the trigger for whichever animation is selected.

Animation Groups

The runtime registers imported animation groups on modelRef.metadata.animationGroups. The linux-animated.glb asset ships with three named groups (foot, happy, head) that this example exposes via radio buttons on the page.

Selection State

The action stores the current animation name on window.__runtime.currentAnimation. Whenever a collision starts, that selection is read back and played. Changing the radio button updates the selection so the next impact plays a different animation.

Source

Attach physics per model mesh, register a collision observer on the first mesh, and play the currently selected animation whenever contact starts. 

<arashtad-model
    id="model_1"
    src="../../../assets/3d/linux-animated.glb"
>
    <arashtad-action
        execute="
            const modelRef = refs['model_1'];
            const meshes = modelRef.metadata?.modelMeshes ?? [];
            const animations = modelRef.metadata?.animationGroups ?? [];

            window.__runtime = window.__runtime || {};
            window.__runtime.animations = animations;
            window.__runtime.currentAnimation = 'happy';

            let firstMesh = null;

            for (const mesh of meshes) {
                const positions = mesh.getVerticesData?.(
                    BABYLON.VertexBuffer.PositionKind
                );

                if (!positions || positions.length === 0) continue;

                const aggregate = new BABYLON.PhysicsAggregate(
                    mesh,
                    BABYLON.PhysicsShapeType.CONVEX_HULL,
                    { mass: 1, restitution: 0.2, friction: 0.6 },
                    scene
                );

                if (!firstMesh) firstMesh = { mesh, aggregate };
            }

            modelRef.position.y += 6;

            window.__runtime.startAnimation = name => {
                const group = animations.find(a => a.name === name)
                    ?? animations.find(a => a.name.includes(name))
                    ?? null;

                if (!group) return;

                for (const other of animations) {
                    if (other !== group) other.stop();
                }

                group.start(true);
                window.__runtime.currentAnimation = name;
            };

            firstMesh.aggregate.body.setCollisionCallbackEnabled(true);

            firstMesh.aggregate.body
                .getCollisionObservable()
                .add(event => {
                    if (event.type !== 'COLLISION_STARTED') return;

                    window.__runtime.startAnimation(
                        window.__runtime.currentAnimation
                    );
                });
        "
    >
    </arashtad-action>
</arashtad-model>
