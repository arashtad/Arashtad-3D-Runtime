Collision Log Panel

Print every collision into a log panel using Arashtad 3D Runtime and Havok physics.

Physics Collision Log

Collision log

Every contact appends a line to the log · click the blue cube to bump both boxes

What this demonstrates

A rolling log of every collision that fires on two physics-enabled boxes, mirrored into a scrollable side panel.

Shared Logger

Both boxes call a shared window.__logCollision helper. Each entry includes the box name, the collision timestamp, and the name of the object it collided against.

Rolling History

The log panel caps its visible entries and scrolls as new ones arrive, so a long running demo stays readable rather than filling the screen.

Source

Both boxes funnel their collision events into a shared helper, which appends formatted entries to the log panel. 

<arashtad-mesh
    id="greenbox"
    type="Box"
    size="1"
    position="new BABYLON.Vector3(-1.5, 6, 0)"
    material="green"
>
    <arashtad-physics
        type="BOX"
        mass="1"
        restitution="0.5"
        friction="0.5"
        startAsleep="false"
    >
        <arashtad-collision
            type="started"
            on-collide="
                window.__logCollision('greenbox', event);
            "
        ></arashtad-collision>
    </arashtad-physics>
</arashtad-mesh>
