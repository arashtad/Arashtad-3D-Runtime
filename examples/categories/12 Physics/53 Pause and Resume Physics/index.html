Pause and Resume Physics

Add buttons that disable and re-enable the physics engine using Arashtad 3D Runtime and Havok physics.

Physics GUI Action
Running
4 dynamic bodies
Pause freezes all bodies in mid-air · Resume restores simulation

What this demonstrates

Toggle Havok simulation on and off without touching the bodies themselves. Meshes keep their transforms while physics is paused, and all motion resumes cleanly.

Engine Toggle

Babylon exposes scene.getPhysicsEngine().setTimeStep(0) and a direct scene.disablePhysicsEngine() / scene.enablePhysics() pair. This example uses the setTimeStep route so the plugin stays attached and no re-initialization cost is paid.

Bodies Stay Intact

Because the aggregates are never disposed, all bodies keep their velocities and internal state. When physics resumes, they continue from exactly where they were frozen.

Source

Two plain HTML buttons toggle the physics engine between running and paused. 

<button type="button" id="pause-button">Pause physics</button>
<button type="button" id="resume-button">Resume physics</button>

<div id="pause-status">Running</div>
