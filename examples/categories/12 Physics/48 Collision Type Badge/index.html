Collision Type Badge

Update a GUI text with the last collision type observed using Arashtad 3D Runtime and Havok physics.

What this demonstrates

Every collision phase reports its type. This example watches event.type and reflects the latest one in a badge in the corner of the demo.

Collision Phases

Havok fires three phases through event.type: COLLISION_STARTED, COLLISION_CONTINUED, and COLLISION_FINISHED. This example listens to all three, without a type filter, so the badge shows whichever phase fires most recently.

Badge Feedback

The badge briefly flashes to highlight each update, so even a rapid stream of COLLISION_CONTINUED events reads as live activity. Timestamp and the other body's name appear below the phase label.

Source

Listen to every collision phase, write event.type into the badge, and flash it briefly for visual feedback. 

<arashtad-mesh
    id="box"
    type="Box"
    size="1.2"
    position="new BABYLON.Vector3(0, 6, 0)"
    material="green"
>
    <arashtad-physics
        type="BOX"
        mass="1"
        restitution="0.6"
        friction="0.5"
        startAsleep="false"
    >
        <arashtad-collision
            on-collide="
                window.__updateCollisionBadge(event);
            "
        ></arashtad-collision>
    </arashtad-physics>
</arashtad-mesh>
