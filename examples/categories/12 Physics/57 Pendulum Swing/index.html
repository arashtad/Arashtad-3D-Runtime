Pendulum Swing

Hang a heavy box from a spherical joint constraint by chaining bodies using Arashtad 3D Runtime and Havok physics.

Physics Advanced Constraint
spherical joint active
A heavy box hanging from an anchor via a ball-and-socket joint

What this demonstrates

The runtime's <arashtad-joint> element composes bodies created by markup into a physical constraint without any imperative JavaScript.

Declarative Joints

The joint is nested inside the anchor mesh and references the weight body by id. The runtime processes all bodies first, then creates joints in a dedicated pass once every reference resolves.

Spherical Joint

type="BALL_AND_SOCKET" locks all rotation of the weight around the pivot and frees translation, so the weight swings freely in any direction while staying attached to the anchor.

Source

The anchor holds the joint. The weight is a separate body that the joint pulls into its arc. 

<arashtad-mesh
    id="anchor"
    type="Box"
    width="0.3"
    height="0.3"
    depth="0.3"
    position="new BABYLON.Vector3(0, 8, 0)"
    material="yellow"
>
    <arashtad-physics
        type="BOX"
        mass="0"
        friction="0.5"
    ></arashtad-physics>

    <arashtad-joint
        type="BALL_AND_SOCKET"
        body="weight"
        pivot="0, 0, 0"
        pivotOther="0, 1.5, 0"
        collision="false"
    ></arashtad-joint>
</arashtad-mesh>

<arashtad-mesh
    id="weight"
    type="Box"
    size="1.4"
    position="new BABYLON.Vector3(2.5, 5, 0)"
    material="red"
>
    <arashtad-physics
        type="BOX"
        mass="3"
        restitution="0.1"
        friction="0.5"
        linearDamping="0.05"
        angularDamping="0.05"
        startAsleep="false"
    ></arashtad-physics>
</arashtad-mesh>
