Click to Drop a Ball

Spawn a dynamic sphere with an impulse on each click using Arashtad 3D Runtime and Havok physics.

Physics Actions Interaction
Click anywhere on the ground → spawn a sphere with an upward impulse

What this demonstrates

Create dynamic bodies at runtime from inside a click handler and attach physics to them on the fly.

Runtime Spawning

The ground's onPickTrigger creates a brand new sphere with MeshBuilder.CreateSphere, assigns a fresh material, and wraps it in a PhysicsAggregate all in one click.

Impulse on Spawn

Each new ball receives an upward impulse immediately, so it launches into the air the moment it appears and then falls back onto the ground.

Source

Spawn dynamic bodies from a click handler and give each one an initial impulse via Havok. 

<arashtad-mesh
    id="ground"
    type="Ground"
    width="20"
    height="20"
    material="brown"
    onPickTrigger="
        const ball = BABYLON.MeshBuilder.CreateSphere(
            'ball_' + Date.now(),
            { diameter: 0.8, segments: 24 },
            scene
        );

        ball.position = new BABYLON.Vector3(0, 8, 0);

        const aggregate = new BABYLON.PhysicsAggregate(
            ball,
            BABYLON.PhysicsShapeType.SPHERE,
            { mass: 1, restitution: 0.5, friction: 0.4 },
            scene
        );

        aggregate.body.applyImpulse(
            new BABYLON.Vector3(0, 8, 0),
            ball.getAbsolutePosition()
        );
    "
>
    <arashtad-physics
        type="BOX"
        mass="0"
        friction="0.6"
    ></arashtad-physics>
</arashtad-mesh>
