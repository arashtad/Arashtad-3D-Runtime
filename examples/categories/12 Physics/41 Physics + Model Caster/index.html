191 · PHYSICS

Physics + Model

Load a GLB model and attach a physics body to it with Arashtad 3D Runtime and Havok physics.

Physics Models Physics
GLB model · CONVEX_HULL per mesh with valid geometry · lifted above the ground

What this demonstrates

Loaded GLB models need explicit physics attachment. Some meshes in the import hierarchy carry no geometry, so the example filters them out before creating aggregates.

Filtering Empty Meshes

Before creating a collider, the expression checks mesh.getVerticesData(PositionKind) and skips any mesh whose vertex list is empty. GLB exports often include pivots and transform nodes that would otherwise break the aggregate.

Lifting the Root

Instead of moving each mesh upward, the model root is lifted. Since each mesh carries a body but their hierarchy stays intact, the whole model drops together on the first frame.

Source

Nest the action inside the model, filter meshes with no geometry, and attach a CONVEX_HULL aggregate per remaining mesh. 

<arashtad-model
    id="model_1"
    src="../../../assets/3d/linux.glb"
>
    <arashtad-action
        execute="
            const modelRef = refs['model_1'];
            const meshes = modelRef.metadata?.modelMeshes ?? [];

            for (const mesh of meshes) {
                const positions = mesh.getVerticesData?.(
                    BABYLON.VertexBuffer.PositionKind
                );

                if (!positions || positions.length === 0) continue;

                new BABYLON.PhysicsAggregate(
                    mesh,
                    BABYLON.PhysicsShapeType.CONVEX_HULL,
                    { mass: 1, restitution: 0.2, friction: 0.6 },
                    scene
                );
            }

            modelRef.position.y += 6;
        "
    >
    </arashtad-action>
</arashtad-model>
