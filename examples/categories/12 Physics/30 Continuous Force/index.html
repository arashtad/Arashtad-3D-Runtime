Continuous Force

Apply a force each frame using an observable on the physics body with Arashtad 3D Runtime and Havok physics.

Physics Force Observable
green · one-time impulse · orange · continuous force each frame

What this demonstrates

A force applied every frame accelerates a body indefinitely, unlike a one-shot impulse which only bumps it once.

Force vs Impulse

An impulse is a single change of momentum, so the green box receives one push and then decelerates due to friction. A force applies every frame, so the orange box keeps accelerating as long as the observable fires.

Observable Loop

The <arashtad-action execute="..."> registers a scene.onBeforeRenderObservable callback that runs every rendered frame. Inside, the action calls applyForce on the body to add a continuous push.

Source

Register the same observable for both boxes, but call applyImpulse once versus applyForce every frame. 

<arashtad-mesh
    id="continuous"
    type="Box"
    size="1"
    position="new BABYLON.Vector3(-4, 0.5, 1.5)"
    material="orange"
>
    <arashtad-physics
        type="BOX"
        mass="1"
        restitution="0.1"
        friction="0.1"
    ></arashtad-physics>

    <arashtad-action
        execute="
            scene.onBeforeRenderObservable.add(() => {
                const aggregate = target.metadata?.physicsAggregate;
                aggregate?.body?.applyForce(
                    new BABYLON.Vector3(30, 0, 0),
                    target.getAbsolutePosition()
                );
            });
        "
    >
    </arashtad-action>
</arashtad-mesh>
