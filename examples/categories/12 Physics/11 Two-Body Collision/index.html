Two-Body Collision

Log collisions between two dynamic boxes and the ground using Arashtad 3D Runtime and Havok physics.

Physics Collision Multiple
Open the console to inspect collision events from both boxes.

What this demonstrates

Attach collision handlers to multiple dynamic bodies and inspect the collision event object that Havok provides.

Multiple Handlers

Each dynamic box has its own <arashtad-collision> element, so collisions on box1 and box2 are reported independently in the console.

Event Object

The event object is logged in full so you can inspect its keys and values, and see exactly what Havok reports on each collision.

Source

Add a separate <arashtad-collision> to each body that should report events. 

<arashtad-mesh
    id="box1"
    type="Box"
    size="1"
    position="new BABYLON.Vector3(0, 8, 0)"
    material="green"
>
    <arashtad-physics
        type="BOX"
        mass="1"
        restitution="0.8"
    >
        <arashtad-collision
            on-collide="
                console.log('EVENT KEYS:', Object.keys(event));
                console.log('EVENT:', event);
            "
        ></arashtad-collision>
    </arashtad-physics>
</arashtad-mesh>

<arashtad-mesh
