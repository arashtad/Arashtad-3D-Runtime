HemisphericLight - Basic

Create a Babylon.js HemisphericLight declaratively and use it to illuminate a simple 3D scene.

Light HemisphericLight Basic

What this demonstrates

The basic declarative setup of a HemisphericLight.

HemisphericLight

The runtime resolves HemisphericLight from Babylon.js and creates it from the supplied direction.

Direction

The light direction is (0, 1, 0), providing illumination from above the scene.

Intensity

The light uses an intensity of 1.2 to provide even illumination across the scene.

Source

A HemisphericLight is created using the runtime light tag. 

<canvas
    id="hemispheric-light-basic"
    clearColor="new BABYLON.Color4(0.04, 0.055, 0.05, 1)">

    <arashtad-runtime resize="engine.resize()">
    </arashtad-runtime>

    <arashtad-camera
        type="ArcRotateCamera"
        id="camera"
        args="BABYLON.Tools.ToRadians(45), BABYLON.Tools.ToRadians(65), 8, new BABYLON.Vector3(0, 0, 0)">
    </arashtad-camera>

    <arashtad-light
        type="HemisphericLight"
        id="light"
        args="new BABYLON.Vector3(0, 1, 0)"
        intensity="1.2">
    </arashtad-light>

    <arashtad-mesh
        type="Box"
        id="box"
        size="2"
        position="new BABYLON.Vector3(0, 0, 0)">
    </arashtad-mesh>

    <arashtad-mesh
        type="Ground"
        id="ground"
        width="8"
        height="8"
        position="new BABYLON.Vector3(0, -1.05, 0)">
    </arashtad-mesh>

</canvas>
