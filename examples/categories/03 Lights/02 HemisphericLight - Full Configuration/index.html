HemisphericLight - Full Configuration

Configure a HemisphericLight declaratively with direction, intensity, diffuse color, ground color, and specular color.

Light HemisphericLight Full Configuration

What this demonstrates

Declarative configuration of the main visual properties of a HemisphericLight.

Direction

The light uses (0, 1, 0) as its direction, representing illumination from above.

Diffuse Color

The diffuse light color is configured with a custom Color3 value to give the illuminated surfaces a green-teal tone.

Ground Color

groundColor controls the color contribution associated with the opposite hemisphere.

Intensity & Specular

The example combines intensity and specular settings with the directional and color configuration.

Source

The complete HemisphericLight configuration is expressed directly through runtime attributes. 

<arashtad-runtime resize="engine.resize()">
</arashtad-runtime>

<arashtad-camera
    type="ArcRotateCamera"
    id="camera"
    args="BABYLON.Tools.ToRadians(45), BABYLON.Tools.ToRadians(65), 9, new BABYLON.Vector3(0, 0.5, 0)"
    lowerBetaLimit="BABYLON.Tools.ToRadians(20)"
    upperBetaLimit="BABYLON.Tools.ToRadians(85)"
    lowerRadiusLimit="5"
    upperRadiusLimit="16"
    inertia="0.8">
</arashtad-camera>

<arashtad-light
    type="HemisphericLight"
    id="light"
    args="new BABYLON.Vector3(0, 1, 0)"
    intensity="1.2"
    diffuse="new BABYLON.Color3(0.3, 0.85, 0.7)"
    groundColor="new BABYLON.Color3(0.85, 0.35, 0.08)"
    specular="new BABYLON.Color3(0.4, 0.4, 0.4)">
</arashtad-light>

<arashtad-material
    type="StandardMaterial"
    id="box-material"
    diffuseColor="new BABYLON.Color3(0.72, 0.78, 0.76)"
    specularColor="new BABYLON.Color3(0.35, 0.35, 0.35)">
</arashtad-material>

<arashtad-mesh
    type="Box"
    id="box"
    size="2"
    material="box-material"
    position="new BABYLON.Vector3(0, 0, 0)">
</arashtad-mesh>

<arashtad-mesh
    type="Sphere"
    id="sphere"
    diameter="1.6"
    material="box-material"
    position="new BABYLON.Vector3(-3, 0, 0)">
</arashtad-mesh>

<arashtad-mesh
    type="Cylinder"
    id="cylinder"
    diameter="1.5"
    height="2.2"
    material="box-material"
    position="new BABYLON.Vector3(3, 0, 0)">
</arashtad-mesh>

<arashtad-mesh
    type="Ground"
    id="ground"
    width="10"
    height="8"
    position="new BABYLON.Vector3(0, -1.05, 0)">
</arashtad-mesh>
