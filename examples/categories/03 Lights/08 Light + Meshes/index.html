34 · Lights

Light + Meshes

Illuminate multiple declarative meshes with different materials to show how runtime lighting affects basic Babylon.js geometry.

Light Meshes Materials

What this demonstrates

Lights, meshes, and materials work together as separate declarative runtime elements.

Multiple Meshes

A box, sphere, cylinder, and torus are created with arashtad-mesh using Babylon.js MeshBuilder types.

Materials

Each mesh uses a separate StandardMaterial, making the lighting differences easy to see.

Key + Rim

A warm directional key light and a cool directional rim light create contrasting illumination across the geometry.

Dark Ground

A dark ground material keeps the focus on the illuminated geometry while retaining the low-key atmosphere.

Source

Meshes and lights are declared directly inside the runtime canvas. 

<arashtad-light
    type="HemisphericLight"
    id="ambient"
    args="new BABYLON.Vector3(0, 1, 0)"
    intensity="0.22"
    diffuse="new BABYLON.Color3(0.12, 0.2, 0.3)"
    groundColor="new BABYLON.Color3(0.015, 0.02, 0.025)"
    specular="new BABYLON.Color3(0.1, 0.12, 0.15)">
</arashtad-light>

<arashtad-light
    type="DirectionalLight"
    id="mainLight"
    args="new BABYLON.Vector3(-0.45, -0.9, 0.35)"
    position="new BABYLON.Vector3(5, 8, -5)"
    intensity="2.4"
    diffuse="new BABYLON.Color3(0.95, 0.42, 0.12)"
    specular="new BABYLON.Color3(0.45, 0.18, 0.06)">
</arashtad-light>
