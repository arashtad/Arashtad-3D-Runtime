37 · Lights

Advanced Lighting Scene

Build a cinematic lighting setup with multiple light sources, different colors, intensities, directions, materials, and dynamic shadows.

Light Advanced Shadows Materials

What this demonstrates

A multi-light scene combining ambient illumination, colored directional lights, materials, and shadows.

Multi-Light Setup

Five independent lights create ambient, warm key, blue rim, green fill, and purple back illumination.

Color & Intensity

Each light uses its own diffuse, specular, and intensity settings to shape the scene's appearance.

Materials

Different diffuse, specular, emissive, and roughness values show how materials react to the layered lighting.

Dynamic Shadows

The main directional light casts shadows from the Linux model and scene objects onto the ground.

Source

Multiple declarative lights are combined with materials, meshes, a model, and a shadow setup. 

<arashtad-light
    type="HemisphericLight"
    id="ambient"
    args="new BABYLON.Vector3(0, 1, 0)"
    intensity="0.12"
    diffuse="new BABYLON.Color3(0.08, 0.14, 0.24)"
    groundColor="new BABYLON.Color3(0.012, 0.008, 0.025)"
    specular="new BABYLON.Color3(0.05, 0.07, 0.1)">
</arashtad-light>

<arashtad-light
    type="DirectionalLight"
