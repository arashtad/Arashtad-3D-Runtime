Light Properties

Configure light intensity, diffuse color, specular color, ground color, direction, and position directly through declarative runtime properties.

Light Properties Configuration

What this demonstrates

Babylon.js light properties can be assigned directly through runtime attributes.

Intensity

The intensity property controls the strength of each light independently.

Colors

diffuse, specular, and groundColor define different aspects of the light's color contribution.

Direction

The directional light receives its direction through the constructor arguments and can then be configured through its other properties.

Position

The directional light also receives a position property through the runtime property system.

Source

Light properties are assigned declaratively through runtime attributes. 

<arashtad-light
    type="HemisphericLight"
    id="ambientLight"
    args="new BABYLON.Vector3(0, 1, 0)"
    intensity="0.35"
    diffuse="new BABYLON.Color3(0.18, 0.3, 0.42)"
    groundColor="new BABYLON.Color3(0.025, 0.03, 0.045)"
    specular="new BABYLON.Color3(0.15, 0.18, 0.22)">
</arashtad-light>

<arashtad-light
    type="DirectionalLight"
    id="mainLight"
    args="new BABYLON.Vector3(-0.5, -1, 0.35)"
    position="new BABYLON.Vector3(5, 8, -5)"
    intensity="2.5"
    diffuse="new BABYLON.Color3(1, 0.38, 0.12)"
    specular="new BABYLON.Color3(0.5, 0.2, 0.08)">
</arashtad-light>
