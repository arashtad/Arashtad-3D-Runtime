DirectionalLight - Basic

Create a Babylon.js DirectionalLight declaratively and illuminate a simple 3D scene from a defined direction.

Light DirectionalLight Basic

What this demonstrates

The basic declarative setup of a DirectionalLight.

DirectionalLight

The runtime resolves DirectionalLight from Babylon.js and constructs it from the supplied direction.

Direction

The light direction is (-1, -2, -1), directing the light toward the scene from above and to one side.

Intensity

The light uses an intensity of 2 to provide strong directional illumination.

Source

A DirectionalLight is created using the runtime light tag. 

<canvas
    id="directional-light-basic"
    clearColor="new BABYLON.Color4(0.04, 0.055, 0.05, 1)">

    <arashtad-runtime resize="engine.resize()">
    </arashtad-runtime>

    <arashtad-camera
        type="ArcRotateCamera"
        id="camera"
        args="BABYLON.Tools.ToRadians(45), BABYLON.Tools.ToRadians(65), 8, new BABYLON.Vector3(0, 0, 0)">
    </arashtad-camera>

    <arashtad-light
        type="DirectionalLight"
        id="light"
        args="new BABYLON.Vector3(-1, -2, -1)"
        intensity="2">
    </arashtad-light>

    <arashtad-mesh
        type="Box"
        id="box"
        size="2"
        position="new BABYLON.Vector3(0, 0, 0)">
    </arashtad-mesh>

    <arashtad-mesh
        type="Ground"
        id="ground"
        width="8"
        height="8"
        position="new BABYLON.Vector3(0, -1.05, 0)">
    </arashtad-mesh>

</canvas>
