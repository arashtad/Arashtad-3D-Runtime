DirectionalLight - Full Configuration

Configure a Babylon.js DirectionalLight declaratively with direction, position, intensity, diffuse color, and specular color.

Light DirectionalLight Full Configuration

What this demonstrates

Declarative configuration of the main properties of a DirectionalLight.

Direction

The light uses (-1, -2, -1) as its direction, sending illumination toward the scene.

Position

The light is positioned at (5, 8, 5), demonstrating that a DirectionalLight can also have a spatial position.

Light Colors

Custom diffuse and specular colors control the light's color contribution and highlights.

Intensity

An intensity of 2 provides a strong directional light source for the scene.

Source

The complete DirectionalLight configuration is expressed through runtime attributes. 

<canvas
    id="directional-light-full"
    clearColor="new BABYLON.Color4(0.025, 0.04, 0.035, 1)">

    <arashtad-runtime resize="engine.resize()">
    </arashtad-runtime>

    <arashtad-camera
        type="ArcRotateCamera"
        id="camera"
        args="BABYLON.Tools.ToRadians(45), BABYLON.Tools.ToRadians(65), 10, new BABYLON.Vector3(0, 0.5, 0)"
        lowerBetaLimit="BABYLON.Tools.ToRadians(20)"
        upperBetaLimit="BABYLON.Tools.ToRadians(85)"
        lowerRadiusLimit="5"
        upperRadiusLimit="18"
        inertia="0.8">
    </arashtad-camera>

    <arashtad-light
        type="DirectionalLight"
        id="light"
        args="new BABYLON.Vector3(-1, -2, -1)"
        position="new BABYLON.Vector3(5, 8, 5)"
        intensity="2"
        diffuse="new BABYLON.Color3(0.3, 0.85, 0.7)"
        specular="new BABYLON.Color3(0.7, 0.7, 0.7)">
    </arashtad-light>

    <arashtad-material
        type="StandardMaterial"
        id="object-material"
        diffuseColor="new BABYLON.Color3(0.7, 0.76, 0.74)"
        specularColor="new BABYLON.Color3(0.4, 0.4, 0.4)">
    </arashtad-material>

    <arashtad-mesh
        type="Box"
        id="box"
        size="2"
        material="object-material"
        position="new BABYLON.Vector3(0, 0, 0)">
    </arashtad-mesh>

    <arashtad-mesh
        type="Sphere"
        id="sphere"
        diameter="1.6"
        material="object-material"
        position="new BABYLON.Vector3(-3, 0, 0)">
    </arashtad-mesh>

    <arashtad-mesh
        type="Cylinder"
        id="cylinder"
        diameter="1.5"
        height="2.2"
        material="object-material"
        position="new BABYLON.Vector3(3, 0, 0)">
    </arashtad-mesh>

    <arashtad-mesh
        type="Ground"
        id="ground"
        width="10"
        height="8"
        position="new BABYLON.Vector3(0, -1.05, 0)">
    </arashtad-mesh>

</canvas>
