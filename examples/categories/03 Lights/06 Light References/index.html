Light References

Create multiple lights declaratively and use runtime references to reuse a light object from another scene element.

Light References Registry

What this demonstrates

Runtime references provide access to previously created objects through their registered IDs.

Light ID

The directional light is registered under keyLight when it is created.

Reference

Another runtime element can use ref="keyLight" to resolve the existing light object instead of constructing another one.

Source

The light is created once and then resolved through its runtime reference. 

<arashtad-light
    type="DirectionalLight"
    id="keyLight"
    args="new BABYLON.Vector3(-0.5, -1, 0.4)"
    position="new BABYLON.Vector3(5, 7, -5)"
    intensity="2.4"
    diffuse="new BABYLON.Color3(1, 0.32, 0.08)"
    specular="new BABYLON.Color3(0.4, 0.15, 0.05)">
</arashtad-light>

<arashtad-mesh
    type="Ground"
    id="ground"
    width="30"
    height="30"
    position="new BABYLON.Vector3(0, -1.15, 0)"
    material="groundMaterial">
</arashtad-mesh>
