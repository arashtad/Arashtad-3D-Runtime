Basic Particle System

A ParticleSystem can be configured entirely through runtime attributes. The particle texture, emitter, emission rate, particle size, lifetime, direction, and emission power define the resulting particle effect.

Configuration

Capacity - 1,000 particles

Texture - ../../../assets/textures/flare.png

Emission Rate - 100 particles per second

Size - 0.2 to 0.5

Lifetime - 1 to 2 seconds

Direction - From (-1, 1, 0) to (1, 2, 0)

Emission Power - 1 to 2

Source

The particle system is created and configured directly through the arashtad-particlesystem runtime element. 

<arashtad-particlesystem
    id="particles"
    type="ParticleSystem"
    capacity="1000"
    particleTexture="new BABYLON.Texture('../../../assets/textures/flare.png', scene)"
    emitter="new BABYLON.Vector3(0, 0, 0)"
    emitRate="100"
    minSize="0.2"
    maxSize="0.5"
    minLifeTime="1"
    maxLifeTime="2"
    direction1="new BABYLON.Vector3(-1, 1, 0)"
    direction2="new BABYLON.Vector3(1, 2, 0)"
    minEmitPower="1"
    maxEmitPower="2">
</arashtad-particlesystem>
