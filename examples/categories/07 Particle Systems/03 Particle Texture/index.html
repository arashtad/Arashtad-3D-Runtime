Particle Texture

96

Configure the texture used by a Babylon.js ParticleSystem through the runtime particleTexture attribute.

Texture: flare.png

Particle Texture

The particleTexture attribute accepts a Babylon.js Texture expression and assigns it to the ParticleSystem. Here the particle texture is loaded from the runtime texture assets.

Configuration

Texture - ../../../assets/textures/flare.png

Texture Type - Babylon.js Texture

Capacity - 1,500 particles

Emission Rate - 150 particles per second

The same texture is rendered on every particle emitted by this system.

Source

Pass a Babylon.js Texture expression to particleTexture when declaring the ParticleSystem. 

<arashtad-particlesystem
    id="particle-texture-system"
    type="ParticleSystem"
    capacity="1500"
    particleTexture="new BABYLON.Texture('../../../assets/textures/flare.png', scene)"
    emitter="new BABYLON.Vector3(0, 0, 0)"
    emitRate="150"
    minSize="0.2"
    maxSize="0.7"
    minLifeTime="1"
    maxLifeTime="2.5"
    direction1="new BABYLON.Vector3(-1, 1, 0)"
    direction2="new BABYLON.Vector3(1, 2, 0)"
    minEmitPower="0.5"
    maxEmitPower="1.5">
</arashtad-particlesystem>
