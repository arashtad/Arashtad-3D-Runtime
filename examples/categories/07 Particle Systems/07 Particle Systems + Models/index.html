Particle Effects Around Models

Imported models and particle systems can coexist as independent runtime elements. Particle emitters can be positioned around a model to create atmospheric, energetic, or environmental effects.

Scene Components

3D Model - The Linux GLB model is imported through the runtime model element.

Primary Particles - A larger particle system surrounds the base of the model.

Secondary Particles - A smaller particle system creates additional particles around the upper part of the model.

Lighting - Hemispheric and directional lights illuminate the model and scene.

Source

Models, lights, and particle systems can be declared independently and composed together in the same runtime scene. 

<arashtad-light
    type="HemisphericLight"
    id="ambient-light"
    args="new BABYLON.Vector3(0, 1, 0)"
    intensity="1.2">
</arashtad-light>

<arashtad-light
    type="DirectionalLight"
    id="model-light"
    args="new BABYLON.Vector3(-0.5, -1, -0.5)"
    intensity="2">
</arashtad-light>

<arashtad-model
    id="model"
    src="../../../assets/3d/linux.glb"
    position="new BABYLON.Vector3(0, 0, 0)"
    scaling="new BABYLON.Vector3(4, 4, 4)">
</arashtad-model>

<arashtad-particlesystem
    id="particles"
    type="ParticleSystem"
    capacity="1500"
    particleTexture="new BABYLON.Texture('../../../assets/textures/flare.png', scene)"
    emitter="new BABYLON.Vector3(0, 0.2, 0)"
    minEmitBox="new BABYLON.Vector3(-0.8, 0, -0.8)"
    maxEmitBox="new BABYLON.Vector3(0.8, 0.2, 0.8)"
    emitRate="180"
    minSize="0.1"
    maxSize="0.5"
    minLifeTime="0.8"
    maxLifeTime="2"
    minEmitPower="0.4"
    maxEmitPower="1.4"
    direction1="new BABYLON.Vector3(-0.5, 1.5, -0.5)"
    direction2="new BABYLON.Vector3(0.5, 2.5, 0.5)"
    gravity="new BABYLON.Vector3(0, 0.3, 0)"
    minAngularSpeed="-1"
    maxAngularSpeed="1"
    color1="new BABYLON.Color4(0.1, 0.8, 0.65, 1)"
    color2="new BABYLON.Color4(0.2, 1, 0.8, 0.9)"
    colorDead="new BABYLON.Color4(0.02, 0.1, 0.08, 0)">
</arashtad-particlesystem>
