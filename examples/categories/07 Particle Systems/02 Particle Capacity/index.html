250 · 1,000 · 2,500 Particle Capacity

Particle Capacity

The capacity determines the maximum number of particles that a ParticleSystem can maintain. Each system can use a different capacity while sharing the same particle configuration.

Configurations

Low - 250 particles

Medium - 1,000 particles

High - 2,500 particles

Each system has its own emitter and particle capacity.

Source

The capacity attribute defines the maximum particle capacity when creating the ParticleSystem. 

<arashtad-particlesystem
    id="low-capacity"
    type="ParticleSystem"
    capacity="250"
    particleTexture="new BABYLON.Texture('../../../assets/textures/flare.png', scene)"
    emitter="new BABYLON.Vector3(-3.5, 0, 0)"
    emitRate="80"
    minSize="0.2"
    maxSize="0.5"
    minLifeTime="1"
    maxLifeTime="2"
    direction1="new BABYLON.Vector3(-0.8, 1, 0)"
    direction2="new BABYLON.Vector3(0.8, 2, 0)"
    minEmitPower="1"
    maxEmitPower="2">
</arashtad-particlesystem>
