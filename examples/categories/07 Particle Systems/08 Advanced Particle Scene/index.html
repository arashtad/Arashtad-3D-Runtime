Advanced Particle Scene

101

Explore an interactive particle scene where presets dynamically transform emission, size, lifetime, gravity, direction, rotation, and color properties.

Particle Control

Switch the entire particle behavior in real time.

ENERGY FIELD High-energy upward particles with fast motion, rotation, and a bright cyan emission.

One System, Many Behaviors

The scene demonstrates how the same ParticleSystem properties can produce dramatically different effects. Use the controls above to modify the live particle systems without rebuilding the scene.

Runtime Properties

Emission - Change the number of particles emitted per second.

Size - Change the maximum particle size while the simulation is running.

Power - Control the maximum velocity applied to newly emitted particles.

Lifetime - Presets demonstrate how short and long particle lifetimes completely change the density of an effect.

Direction - Each preset changes the direction vectors to create fountains, flames, storms, or rising mist.

Gravity - Positive, negative, and near-zero gravity produce fundamentally different particle motion.

Rotation - Angular speed adds another dimension of movement to the particle simulation.

Color - Multiple color stages control the visual transition of particles throughout their lifetime.

Source

The initial scene is declarative. JavaScript is used only for runtime interaction, allowing the same Babylon.js ParticleSystem properties to be changed through the controls. 

<arashtad-particlesystem
    id="primary-particles"
    type="ParticleSystem"
    capacity="3500"
    particleTexture="new BABYLON.Texture('../../../assets/textures/flare.png', scene)"
    emitter="new BABYLON.Vector3(0, 0.2, 0)"
    minEmitBox="new BABYLON.Vector3(-0.9, 0, -0.9)"
    maxEmitBox="new BABYLON.Vector3(0.9, 0.15, 0.9)"
    emitRate="260"
    minSize="0.12"
    maxSize="0.7"
    minLifeTime="0.6"
    maxLifeTime="2.2"
    minEmitPower="0.5"
    maxEmitPower="2.2"
    direction1="new BABYLON.Vector3(-0.8, 1.5, -0.8)"
    direction2="new BABYLON.Vector3(0.8, 3.5, 0.8)"
    gravity="new BABYLON.Vector3(0, 0.4, 0)"
    minAngularSpeed="-2"
    maxAngularSpeed="2"
    color1="new BABYLON.Color4(0.1, 0.8, 0.65, 1)"
    color2="new BABYLON.Color4(0.2, 1, 0.8, 0.9)"
    colorDead="new BABYLON.Color4(0.01, 0.05, 0.04, 0)">
</arashtad-particlesystem>

<script type="module">
    import { ready } from '../../../../lib/arashtad/arashtad-3d-runtime-1.1.0.min.js';

    const canvas = document.getElementById('advanced-particles');
    const scene = await ready(canvas);

    const particles = scene.particleSystems.find(
        system => system.name === 'primary-particles'
    );

    particles.emitRate = 420;
    particles.maxSize = 1.2;
    particles.maxEmitPower = 3;
    particles.gravity = new BABYLON.Vector3(0, 0.8, 0);
</script>
