ParticleSystem Properties

ParticleSystem properties control how particles are emitted, moved, sized, colored, rotated, and removed. Multiple properties can be combined on the same runtime element.

Properties

Emission - emitRate, minEmitBox, maxEmitBox

Size - minSize, maxSize

Lifetime - minLifeTime, maxLifeTime

Direction - direction1, direction2

Power - minEmitPower, maxEmitPower

Gravity - gravity

Rotation - minAngularSpeed, maxAngularSpeed

Color - color1, color2, colorDead

Source

These properties are assigned directly to the Babylon.js ParticleSystem through runtime attributes. 

<arashtad-particlesystem
    id="particles"
    type="ParticleSystem"
    capacity="1000"
    particleTexture="new BABYLON.Texture('../../../assets/textures/flare.png', scene)"
    emitter="new BABYLON.Vector3(0, 0, 0)"
    emitRate="100"
    minSize="0.2"
    maxSize="0.5"
    minLifeTime="1"
    maxLifeTime="2"
    direction1="new BABYLON.Vector3(-1, 1, 0)"
    direction2="new BABYLON.Vector3(1, 2, 0)"
    minEmitPower="1"
    maxEmitPower="2">
</arashtad-particlesystem>
