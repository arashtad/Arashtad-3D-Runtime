Combine multiple independent ParticleSystem elements in a single scene, each with its own emitter, capacity, emission settings, movement, and appearance.

3 Independent Particle Systems

Multiple Particle Systems

Multiple ParticleSystem elements can coexist in the same runtime scene. Each system is created independently and can use different capacities, emitters, rates, directions, lifetimes, sizes, gravity, rotation, and colors.

Particle Systems

Fire - 2,000 capacity with high emission, gravity, rotation, and short lifetimes.

Particles - 1,000 capacity with moderate emission and directional movement.

Smoke - 1,500 capacity with larger particles, longer lifetimes, low emission power, and light gravity.

Source

Each ParticleSystem is declared as an independent runtime element. All systems are initialized as part of the same scene. 

<arashtad-particlesystem
    id="fire"
    type="ParticleSystem"
    capacity="2000"
    particleTexture="new BABYLON.Texture('../../../assets/textures/flare.png', scene)"
    emitter="new BABYLON.Vector3(-3.5, 0, 0)"
    minEmitBox="new BABYLON.Vector3(-0.5, 0, -0.5)"
    maxEmitBox="new BABYLON.Vector3(0.5, 0.1, 0.5)"
    emitRate="300"
    minSize="0.1"
    maxSize="0.8"
    minLifeTime="0.3"
    maxLifeTime="1.2"
    minEmitPower="0.5"
    maxEmitPower="2"
    direction1="new BABYLON.Vector3(-0.5, 2, -0.5)"
    direction2="new BABYLON.Vector3(0.5, 4, 0.5)"
    gravity="new BABYLON.Vector3(0, 1, 0)"
    minAngularSpeed="-2"
    maxAngularSpeed="2"
    color1="new BABYLON.Color4(1, 0.2, 0, 1)"
    color2="new BABYLON.Color4(1, 0.8, 0, 1)"
    colorDead="new BABYLON.Color4(0.2, 0, 0, 0)">
</arashtad-particlesystem>
