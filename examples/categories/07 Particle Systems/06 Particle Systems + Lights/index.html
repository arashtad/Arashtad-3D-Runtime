Particle Systems + Lights

Particle systems and scene lights can be declared independently in the same runtime scene. The lights provide scene illumination while the particle systems define their own visual appearance through textures and particle colors.

Scene Components

Ambient Light - HemisphericLight with an upward direction and moderate intensity.

Particle Light - PointLight positioned above the particle emitter.

Main Particles - 1,500-particle system with gravity, rotation, and colored particles.

Secondary Particles - Independent 800-particle system with smaller particles and a lower emission rate.

Source

Lights and particle systems are separate runtime elements and can be combined freely in the same scene. 

<arashtad-light
    type="HemisphericLight"
    id="ambient-light"
    args="new BABYLON.Vector3(0, 1, 0)"
    intensity="0.8">
</arashtad-light>

<arashtad-light
    type="PointLight"
    id="particle-light"
    args="new BABYLON.Vector3(0, 2, 0)"
    intensity="3">
</arashtad-light>

<arashtad-particlesystem
    id="particles"
    type="ParticleSystem"
    capacity="1500"
    particleTexture="new BABYLON.Texture('../../../assets/textures/flare.png', scene)"
    emitter="new BABYLON.Vector3(0, 0, 0)"
    minEmitBox="new BABYLON.Vector3(-0.5, 0, -0.5)"
    maxEmitBox="new BABYLON.Vector3(0.5, 0.1, 0.5)"
    emitRate="180"
    minSize="0.15"
    maxSize="0.7"
    minLifeTime="0.5"
    maxLifeTime="1.8"
    minEmitPower="0.5"
    maxEmitPower="1.8"
    direction1="new BABYLON.Vector3(-0.5, 1.5, -0.5)"
    direction2="new BABYLON.Vector3(0.5, 3, 0.5)"
    gravity="new BABYLON.Vector3(0, 0.5, 0)"
    minAngularSpeed="-1"
    maxAngularSpeed="1"
    color1="new BABYLON.Color4(1, 0.25, 0.05, 1)"
    color2="new BABYLON.Color4(1, 0.75, 0.1, 1)"
    colorDead="new BABYLON.Color4(0.15, 0.02, 0, 0)">
</arashtad-particlesystem>
