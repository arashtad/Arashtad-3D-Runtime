Model Loading Errors

Handle model loading failures with a runtime-level error callback while continuing to display loading progress.

Model Error Handling OnLoadError
Loading Scene
0%

What this demonstrates

Runtime-level handling of model loading failures.

OnLoadError

The runtime calls OnLoadError when a model fails to load. The callback receives the loading error message through message.

Failed Model

The second model intentionally references a nonexistent GLB file so the error handler can be observed without modifying the runtime.

Source

Model loading errors are handled through the runtime's scene-level error callback. 

<canvas
    id="model-loading-errors"
    class="loading"
    clearColor="new BABYLON.Color4(0.008, 0.012, 0.018, 1)"
>

    <arashtad-runtime
        resize="engine.resize()"
        OnLoadProgress="
            document.getElementById('loading-counter').textContent = progress + '%';
            document.getElementById('loading-bar').style.width = progress + '%';

            if (progress >= 100) {
                setTimeout(() => {
                    document.getElementById('model-loading-errors').classList.remove('loading');
                    document.getElementById('model-loading-errors').classList.add('loaded');
                    document.getElementById('preloader').classList.add('hidden');
                }, 200);
            }
        "
        OnLoadError="
            const error = document.getElementById('loading-error');
            error.textContent = 'Model loading error: ' + message;
            error.classList.add('visible');
        "
    ></arashtad-runtime>

    <arashtad-camera
        type="ArcRotateCamera"
        id="camera"
        args="Math.PI / 2, Math.PI / 2.4, 6, new BABYLON.Vector3(0, -0.2, 0)"
        minZ="0.1"
        maxZ="1000"
    ></arashtad-camera>

    <arashtad-light
        type="HemisphericLight"
        id="light"
        args="new BABYLON.Vector3(0, 1, 0)"
        intensity="1.3"
    ></arashtad-light>

    <arashtad-model
        id="valid-model"
        src="../../../assets/3d/linux.glb"
        position="new BABYLON.Vector3(0, -0.5, 0)"
        scaling="new BABYLON.Vector3(5, 5, 5)"
    ></arashtad-model>

    <arashtad-model
        id="invalid-model"
        src="../../../assets/3d/model-that-does-not-exist.glb"
    ></arashtad-model>

</canvas>

<div id="preloader">
    <div id="preloader-spinner"></div>
    <div id="loading-label">Loading Scene</div>
    <div id="loading-counter">0%</div>
    <div id="loading-track">
        <div id="loading-bar"></div>
    </div>
    <div id="loading-error"></div>
</div>
