Multiple Model Loading Progress

Load multiple GLB models while displaying a complete scene-level preloader driven by the runtime loading progress.

Model Multiple Preloader
Loading Scene
0%

What this demonstrates

A complete scene preloader driven by aggregate model loading progress.

Aggregate Progress

The runtime tracks the loading progress of all three models and exposes the current value as progress through OnLoadProgress.

Preloader

The callback updates both the percentage and progress bar. Once loading reaches 100%, the preloader fades away and the scene becomes visible.

Source

The complete preloader is controlled by the runtime's scene-level progress callback. 

<canvas
    id="multiple-model-loading-progress"
    class="loading"
    clearColor="new BABYLON.Color4(0.008, 0.012, 0.018, 1)"
>

    <arashtad-runtime
        resize="engine.resize()"
        OnLoadProgress="
            document.getElementById('loading-counter').textContent = progress + '%';
            document.getElementById('loading-bar').style.width = progress + '%';

            if (progress >= 100) {
                setTimeout(() => {
                    document.getElementById('multiple-model-loading-progress').classList.remove('loading');
                    document.getElementById('multiple-model-loading-progress').classList.add('loaded');
                    document.getElementById('preloader').classList.add('hidden');
                }, 200);
            }
        "
    ></arashtad-runtime>

    <arashtad-camera
        type="ArcRotateCamera"
        id="camera"
        args="Math.PI / 2, Math.PI / 2.4, 8, new BABYLON.Vector3(0, 1, 0)"
        minZ="0.1"
        maxZ="1000"
    ></arashtad-camera>

    <arashtad-light
        type="HemisphericLight"
        id="light"
        args="new BABYLON.Vector3(0, 1, 0)"
        intensity="1.3"
    ></arashtad-light>

    <arashtad-model
        id="linux-left"
        src="../../../assets/3d/linux.glb"
        position="new BABYLON.Vector3(-1.8, -0.5, 0)"
        scaling="new BABYLON.Vector3(3.5, 3.5, 3.5)"
    ></arashtad-model>

    <arashtad-model
        id="linux-center"
        src="../../../assets/3d/linux.glb"
        position="new BABYLON.Vector3(0, -0.5, 0)"
        scaling="new BABYLON.Vector3(5, 5, 5)"
    ></arashtad-model>

    <arashtad-model
        id="linux-right"
        src="../../../assets/3d/linux.glb"
        position="new BABYLON.Vector3(1.8, -0.5, 0)"
        scaling="new BABYLON.Vector3(3.5, 3.5, 3.5)"
    ></arashtad-model>

</canvas>

    <div id="loading-counter">0%</div>
    <div id="loading-track">
        <div id="loading-bar"></div>
