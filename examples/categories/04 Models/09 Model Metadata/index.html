Model Metadata

After a model is imported, the runtime-created model root contains metadata describing the imported model data. The metadata includes the imported meshes and animation groups.

modelMeshes

An array containing the meshes imported from the model. For linux.glb, this includes the model's imported mesh hierarchy.

animationGroups

An array containing the animation groups imported from the model. The runtime stores these groups alongside the model meshes in the root metadata.

Inspecting the Metadata

The runtime-created model root can be retrieved from the Babylon scene and its metadata inspected through the normal Babylon API.

Model Root

The model with ID linux creates a runtime root named linux-root.

The example retrieves that root with scene.getTransformNodeByName().

Metadata

The example reads modelRoot.metadata.modelMeshes and modelRoot.metadata.animationGroups and displays the results directly on the page.

Runtime Metadata Structure

The metadata stored on the runtime-created model root provides direct access to the imported model components. 

linux-root
└── metadata
    ├── modelMeshes
    │   ├── imported mesh
    │   ├── imported mesh
    │   └── ...
    │
    └── animationGroups
        ├── animation group
        ├── animation group
        └── ...

Source

The model is loaded declaratively, while the returned Babylon scene is used to inspect the runtime-created model metadata. 

<arashtad-model
    id="linux"
    src="../../../assets/3d/linux.glb"
    position="new BABYLON.Vector3(0, -0.5, 0)"
    scaling="new BABYLON.Vector3(5, 5, 5)"
></arashtad-model>

<script type="module">
    import { ready } from '../../../../lib/arashtad/arashtad-3d-runtime.1.0.0.min.js';

    const canvas = document.getElementById('model-metadata');

    const scene = await ready(canvas);

    const modelRoot = scene.getTransformNodeByName('linux-root');

    const modelMeshes = modelRoot.metadata.modelMeshes;
    const animationGroups = modelRoot.metadata.animationGroups;

    document.getElementById('model-metadata-status').innerHTML =
        '<strong>Meshes:</strong> ' + modelMeshes.length +
        '   ' +
        '<strong>Animation groups:</strong> ' + animationGroups.length;
</script>
