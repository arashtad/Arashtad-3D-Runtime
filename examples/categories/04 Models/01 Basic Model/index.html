Basic Model

Load a glTF model declaratively and place it into a simple Babylon.js scene using the Arashtad 3D Runtime.

Model GLB Basic

What this demonstrates

The basic declarative model-loading workflow.

Model Loading

The runtime loads the GLB file through Babylon.js SceneLoader using the arashtad-model tag.

Model Source

The model is loaded from ../../../assets/3d/linux.glb and registered under the identifier linux.

Source

A GLB model is loaded declaratively with the runtime model tag. 

<canvas id="basic-model">

    <arashtad-runtime resize="engine.resize()">
    </arashtad-runtime>

    <arashtad-camera
        type="ArcRotateCamera"
        id="camera"
        args="Math.PI / 2, Math.PI / 2.4, 9, new BABYLON.Vector3(0, 1, 0)">
    </arashtad-camera>

    <arashtad-light
        type="HemisphericLight"
        id="light"
        args="new BABYLON.Vector3(0, 1, 0)"
        intensity="1.4">
    </arashtad-light>

    <arashtad-model
        id="linux"
        src="../../../assets/3d/linux.glb"
        position="new BABYLON.Vector3(0, -0.5, 0)"
        scaling="new BABYLON.Vector3(5, 5, 5)">
    </arashtad-model>

</canvas>

<script src="../../../../lib/babylon/babylon.js"></script>
<script src="../../../../lib/babylon/loaders/babylonjs.loaders.min.js"></script>

<script type="module">
    import { ready } from '../../../../lib/arashtad/arashtad-3d-runtime-1.1.0.min.js';

    const canvas = document.getElementById('basic-model');

    await ready(canvas);
</script>
