Automatic Mesh Registration

When an external model is imported, Arashtad 3D Runtime registers its named meshes in the runtime registry. The linux.glb model contains three named meshes: black, white, and orange.

Registered Meshes
linux.glb
├── black    → registered as "black"
├── white    → registered as "white"
└── orange   → registered as "orange"
Direct References

Once registered, an imported mesh can be addressed directly with its registered name.

This example uses <arashtad-mesh ref="..."> to attach an event to each imported mesh.

Registered Mesh References

The three references below resolve to the actual meshes imported from linux.glb. Click each part in the scene to verify the registration visually.

black

Registered from the imported mesh named black.

white

Registered from the imported mesh named white.

orange

Registered from the imported mesh named orange.

Source

The model is imported normally. Its individual meshes are then resolved from the runtime registry by name. 

<arashtad-model
    id="linux"
    src="../../../assets/3d/linux.glb"
    position="new BABYLON.Vector3(0, -0.5, 0)"
    scaling="new BABYLON.Vector3(5, 5, 5)"
>

    <arashtad-mesh
        ref="black"
        OnPickTrigger="
            document.getElementById('mesh-registration-status').innerHTML =
                '<strong>Registered mesh:</strong> black';
        "
    ></arashtad-mesh>

    <arashtad-mesh
        ref="white"
        OnPickTrigger="
            document.getElementById('mesh-registration-status').innerHTML =
                '<strong>Registered mesh:</strong> white';
        "
    ></arashtad-mesh>

    <arashtad-mesh
        ref="orange"
        OnPickTrigger="
            document.getElementById('mesh-registration-status').innerHTML =
                '<strong>Registered mesh:</strong> orange';
        "
    ></arashtad-mesh>

</arashtad-model>
