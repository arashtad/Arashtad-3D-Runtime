Model IDs and References

Give loaded models stable IDs and use runtime references to connect other scene objects to those models.

Model References IDs

What this demonstrates

Model identifiers and runtime registry references.

Model ID

The linux model is registered using its id, making it available through the runtime registry.

Reference

Runtime expressions can resolve registered objects by their IDs. The marker uses the linux reference to modify the loaded model when picked.

Source

The model ID becomes a runtime reference that can be used by scene expressions. 

<canvas id="model-ids-references">

    <arashtad-runtime resize="engine.resize()">
    </arashtad-runtime>

    <arashtad-camera
        type="ArcRotateCamera"
        id="camera"
        args="Math.PI / 2, Math.PI / 2.4, 6.5, new BABYLON.Vector3(0, 0, 0)">
    </arashtad-camera>

    <arashtad-light
        type="HemisphericLight"
        id="light"
        args="new BABYLON.Vector3(0, 1, 0)"
        intensity="1.3">
    </arashtad-light>

    <arashtad-model
        id="linux"
        src="../../../assets/3d/linux.glb"
        position="new BABYLON.Vector3(0, -0.5, 0)"
        scaling="new BABYLON.Vector3(5, 5, 5)">
    </arashtad-model>

    <arashtad-mesh
        type="Box"
        id="platform"
        size="2.8"
        position="new BABYLON.Vector3(0, -1.9, 0)"
        scaling="new BABYLON.Vector3(1.8, 0.25, 1.8)">
    </arashtad-mesh>

    <arashtad-mesh
        type="Torus"
        id="ring"
        diameter="2.8"
        thickness="0.08"
        position="new BABYLON.Vector3(0, -1.55, 0)">
    </arashtad-mesh>

    <arashtad-mesh
        type="Box"
        id="reference-marker"
        size="0.45"
        position="new BABYLON.Vector3(0, 2.4, 0)"
        OnPickTrigger="linux.scaling = new BABYLON.Vector3(4.2, 4.2, 4.2);">
    </arashtad-mesh>

</canvas>
