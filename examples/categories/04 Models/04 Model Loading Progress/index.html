Model Loading Progress

Monitor the loading progress of a model through the runtime and display the current aggregate loading percentage.

Model Loading Progress
0%

What this demonstrates

Runtime-level progress reporting while models are loaded.

OnLoadProgress

The runtime accepts an OnLoadProgress handler on arashtad-runtime. The handler receives the current aggregate progress value.

Aggregate Progress

The runtime tracks model loading progress and reports a single percentage for the scene. The value reaches 100 when loading and model processing are complete.

Source

The runtime progress callback updates the loading indicator. 

<canvas id="model-loading-progress">

    <arashtad-runtime
        resize="engine.resize()"
        OnLoadProgress="
            const counter = document.getElementById('model-progress');
            counter.textContent = progress + '%';
        "
    ></arashtad-runtime>

    <arashtad-camera
        type="ArcRotateCamera"
        id="camera"
        args="Math.PI / 2, Math.PI / 2.4, 6.5, new BABYLON.Vector3(0, -0.1, 0)">
    </arashtad-camera>

    <arashtad-light
        type="HemisphericLight"
        id="light"
        args="new BABYLON.Vector3(0, 1, 0)"
        intensity="1.3">
    </arashtad-light>

    <arashtad-model
        id="linux"
        src="../../../assets/3d/linux.glb"
        position="new BABYLON.Vector3(0, -0.5, 0)"
        scaling="new BABYLON.Vector3(5, 5, 5)">
    </arashtad-model>

</canvas>
