Multiple Models

Load multiple GLB models declaratively and arrange them independently inside the same Babylon.js scene.

Model Multiple GLB

What this demonstrates

Multiple independent model instances in one scene.

Multiple Instances

Each arashtad-model loads its own GLB instance into the same Babylon.js scene.

Independent Transforms

Each model has its own position and scaling, allowing the instances to be arranged independently.

Source

Three independent GLB model instances are declared in the same canvas. 

<canvas id="multiple-models">

    <arashtad-runtime resize="engine.resize()">
    </arashtad-runtime>

    <arashtad-camera
        type="ArcRotateCamera"
        id="camera"
        args="Math.PI / 2, Math.PI / 2.5, 8, new BABYLON.Vector3(0, 1, 0)">
    </arashtad-camera>

    <arashtad-light
        type="HemisphericLight"
        id="light"
        args="new BABYLON.Vector3(0, 1, 0)"
        intensity="1.3">
    </arashtad-light>

    <arashtad-model
        id="linux-left"
        src="../../../assets/3d/linux.glb"
        position="new BABYLON.Vector3(-1.8, -0.5, 0)"
        scaling="new BABYLON.Vector3(3.5, 3.5, 3.5)">
    </arashtad-model>

    <arashtad-model
        id="linux-center"
        src="../../../assets/3d/linux.glb"
        position="new BABYLON.Vector3(0, -0.5, 0)"
        scaling="new BABYLON.Vector3(5, 5, 5)">
    </arashtad-model>

    <arashtad-model
        id="linux-right"
        src="../../../assets/3d/linux.glb"
        position="new BABYLON.Vector3(1.8, -0.5, 0)"
        scaling="new BABYLON.Vector3(3.5, 3.5, 3.5)">
    </arashtad-model>

</canvas>

<script src="../../../../lib/babylon/babylon.js"></script>
