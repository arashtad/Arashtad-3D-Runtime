Runtime Object References

Give runtime objects an ID and reference them from other runtime elements without recreating the underlying Babylon.js object.

Runtime References Registry Objects
ARASHTAD 3D RUNTIME · 09

What this demonstrates

Runtime IDs register created objects so other elements can resolve and use those objects directly.

References

  • Object registration by ID
  • Reference resolution
  • Shared Babylon.js objects
  • Material reference assignment

Reference

material="shared-material"

Source

The material receives an ID and both meshes resolve the same registered material through that reference. 

<canvas id="reference-demo">

    <arashtad-runtime
        resize="engine.resize()">
    </arashtad-runtime>

    <arashtad-camera
        type="ArcRotateCamera"
        id="camera"
        alpha="BABYLON.Tools.ToRadians(90)"
        beta="BABYLON.Tools.ToRadians(70)"
        radius="8"
        target="new BABYLON.Vector3(0, 0, 0)">
    </arashtad-camera>

    <arashtad-light
        type="HemisphericLight"
        id="light"
        direction="new BABYLON.Vector3(0, 1, 0)"
        intensity="1.2">
    </arashtad-light>

    <arashtad-material
        type="StandardMaterial"
        id="shared-material"
        diffuseColor="new BABYLON.Color3(0.15, 0.65, 0.55)">
    </arashtad-material>

    <arashtad-mesh
        type="Box"
        id="box"
        size="2"
        material="shared-material">
    </arashtad-mesh>

    <arashtad-mesh
        type="Sphere"
        id="sphere"
        diameter="1.4"
        position="new BABYLON.Vector3(0, 1.8, 0)"
        material="shared-material">
    </arashtad-mesh>

</canvas>
