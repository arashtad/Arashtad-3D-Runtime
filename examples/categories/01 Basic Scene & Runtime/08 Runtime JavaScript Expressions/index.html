Runtime JavaScript Expressions

Use JavaScript expressions directly in runtime attributes to construct vectors, colors, angles, and other Babylon.js values declaratively.

Runtime Expressions Babylon.js Properties
ARASHTAD 3D RUNTIME · 08

What this demonstrates

Runtime attributes can contain JavaScript expressions that are evaluated when the scene is constructed.

Expressions

  • JavaScript expression evaluation
  • Babylon.js Vector3 construction
  • Babylon.js Color3 construction
  • Static Babylon.js method calls
  • Runtime property parsing
  • Declarative scene construction

Examples

new BABYLON.Vector3(0, 0, 0)
new BABYLON.Color3(0.3, 0.8, 0.7)
BABYLON.Tools.ToRadians(90)

Source

Values such as vectors, colors, and angles can be written directly inside runtime attributes as JavaScript expressions. 

<canvas id="expression-demo">

    <arashtad-runtime resize="engine.resize()"></arashtad-runtime>

    <arashtad-camera
        type="ArcRotateCamera"
        id="camera"
        alpha="BABYLON.Tools.ToRadians(90)"
        beta="BABYLON.Tools.ToRadians(70)"
        radius="8"
        target="new BABYLON.Vector3(0, 0, 0)">
    </arashtad-camera>

    <arashtad-light
        type="HemisphericLight"
        id="light"
        direction="new BABYLON.Vector3(0, 1, 0)"
        diffuse="new BABYLON.Color3(0.3, 0.8, 0.7)"
        intensity="1.2">
    </arashtad-light>

    <arashtad-mesh
        type="Box"
        id="box"
        size="2"
        position="new BABYLON.Vector3(0, 0, 0)"
        rotation="new BABYLON.Vector3(
            BABYLON.Tools.ToRadians(30),
            0,
            0
        )">
    </arashtad-mesh>

</canvas>
