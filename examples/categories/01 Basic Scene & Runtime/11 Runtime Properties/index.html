What this demonstrates

Runtime-level configuration and triggers declared directly on the runtime element.

Runtime Properties

  • Canvas resize expression
  • Environment texture
  • Environment intensity
  • Environment background
  • Environment background blur
  • Environment rotation

Runtime Triggers

  • Native JavaScript DOM trigger
  • Babylon.js pointer observable
  • Runtime load progress
  • Runtime load error
  • Inline JavaScript execution

Source

All runtime properties and runtime-level triggers are declared on <arashtad-runtime>. 

<canvas id="runtime-properties">

    <arashtad-runtime
        resize="engine.resize()"
        environment="../../../assets/environments/room.hdr"
        environmentIntensity="1"
        environmentBackground="true"
        environmentBackgroundBlur="0.1"
        environmentRotationY="1"
        on-click="document.getElementById('runtime-status').textContent = 'Runtime DOM click trigger';"
        onpointerdown="document.getElementById('runtime-status').textContent = 'Runtime Babylon pointerdown trigger';"
        OnLoadProgress="document.getElementById('runtime-status').textContent = 'Loading: ' + progress + '%';"
        OnLoadError="document.getElementById('runtime-status').textContent = 'Runtime load error';">
    </arashtad-runtime>

    <arashtad-camera
        type="ArcRotateCamera"
        id="camera"
        args="BABYLON.Tools.ToRadians(90), BABYLON.Tools.ToRadians(65), 8, new BABYLON.Vector3(0, 0, 0)">
    </arashtad-camera>

    <arashtad-light
        type="HemisphericLight"
        id="light"
        args="new BABYLON.Vector3(0, 1, 0)"
        intensity="1.2">
    </arashtad-light>

    <arashtad-mesh
        type="Box"
        id="box"
        size="2">
    </arashtad-mesh>

</canvas>

<script src="../../../../lib/babylon/babylon.js"></script>

<script type="module">
