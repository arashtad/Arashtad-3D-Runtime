Basic Scene

Create a complete Arashtad 3D Runtime scene with a canvas, camera, light, and a simple mesh.

ARASHTAD 3D RUNTIME · 01

What this demonstrates

The minimum complete declarative 3D scene required to render visible geometry.

Scene

  • HTML canvas integration
  • Arashtad 3D Runtime initialization
  • ArcRotateCamera
  • HemisphericLight
  • MeshBuilder Box
  • Declarative scene construction

Runtime API

ready(canvas);

Source

The scene is declared directly inside the canvas. JavaScript only initializes the runtime. 

<canvas id="basic-scene">

    <arashtad-camera
        type="ArcRotateCamera"
        id="camera"
        alpha="1.57"
        beta="1.2"
        radius="8"
        target="new BABYLON.Vector3(0, 0, 0)">
    </arashtad-camera>

    <arashtad-light
        type="HemisphericLight"
        id="light"
        direction="new BABYLON.Vector3(0, 1, 0)">
    </arashtad-light>

    <arashtad-mesh
        type="Box"
        id="box"
        size="2">
    </arashtad-mesh>

</canvas>

<script src="../../../../lib/babylon/babylon.js"></script>

<script type="module">
    import { ready } from '../../../../lib/arashtad/arashtad-3d-runtime-1.1.0.min.js';

    const canvas = document.getElementById('basic-scene');

    ready(canvas);
</script>
