Runtime Constructor Arguments

Override the default constructor argument mapping and pass custom JavaScript expressions directly to a Babylon.js constructor.

Runtime Constructors Arguments Expressions
ARASHTAD 3D RUNTIME · 10

What this demonstrates

The args attribute provides an explicit constructor argument list instead of using the runtime's default argument mapping.

Constructor

  • Explicit constructor arguments
  • JavaScript expressions in arguments
  • Babylon.js constructor resolution
  • Custom argument ordering
  • Declarative object construction

Arguments

args="alpha, beta, radius, target"

Source

The camera receives its complete constructor argument list through the args attribute. 

<canvas id="constructor-demo">

    <arashtad-runtime
        resize="engine.resize()">
    </arashtad-runtime>

    <arashtad-camera
        type="ArcRotateCamera"
        id="camera"
        args="BABYLON.Tools.ToRadians(90), BABYLON.Tools.ToRadians(65), 8, new BABYLON.Vector3(0, 0, 0)">
    </arashtad-camera>

    <arashtad-light
        type="HemisphericLight"
        id="light"
        args="new BABYLON.Vector3(0, 1, 0)"
        intensity="1.2">
    </arashtad-light>

    <arashtad-mesh
        type="Box"
        id="box"
        size="2">
    </arashtad-mesh>

</canvas>

<script src="../../../../lib/babylon/babylon.js"></script>

<script type="module">
    import { ready } from '../../../../lib/arashtad/arashtad-3d-runtime-1.1.0.min.js';

    const canvas = document.getElementById('constructor-demo');

    await ready(canvas);
</script>
