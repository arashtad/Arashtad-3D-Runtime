Runtime Resize

Use the runtime resize expression to execute engine.resize() whenever the canvas changes size.

Runtime Resize Engine

Runtime Resize

The runtime executes engine.resize() when the canvas size changes.

ARASHTAD 3D RUNTIME · 04

What this demonstrates

Runtime expressions can directly access the Babylon.js engine.

Runtime

  • <arashtad-runtime>
  • resize expression
  • engine reference
  • engine.resize()
  • Responsive canvas rendering

Configuration

resize="engine.resize()"

Source

The resize attribute contains the expression executed by the runtime. 

<canvas id="resize-demo">

    <arashtad-runtime
        resize="engine.resize()">
    </arashtad-runtime>

    <arashtad-camera
        type="ArcRotateCamera"
        id="camera"
        alpha="1.57"
        beta="1.2"
        radius="8"
        target="new BABYLON.Vector3(0, 0, 0)">
    </arashtad-camera>

    <arashtad-light
        type="HemisphericLight"
        id="light"
        direction="new BABYLON.Vector3(0, 1, 0)"
        intensity="1.2">
    </arashtad-light>

    <arashtad-mesh
        type="Box"
        id="box"
        size="2">
    </arashtad-mesh>

</canvas>

<script src="../../../../lib/babylon/babylon.js"></script>

<script type="module">
    import { ready } from '../../../../lib/arashtad/arashtad-3d-runtime-1.1.0.min.js';

    const canvas = document.getElementById('resize-demo');

    await ready(canvas);
</script>
