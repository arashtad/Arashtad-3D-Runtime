147 · SHADOWS

Multiple Receivers

Configure multiple scene meshes on different surfaces to receive shadows from the same Babylon.js ShadowGenerator.

Shadows Receiver
Shadow caster: model_1
Receivers: ground, wall_back

What this demonstrates

Multiple receiver references can be attached to one ShadowGenerator, allowing different surfaces to receive shadows from the same light.

Multiple Surfaces

The ground and two walls are independently configured as shadow receivers using separate receiver references.

Shared Generator

All three surfaces receive shadows from the same caster, directional light, and ShadowGenerator.

Source

Configure multiple meshes as receivers within the same shadow configuration. 

<arashtad-shadow
    light="directional"
    mapSize="2048"
    darkness="0.3"
    minZ="0.1"
    maxZ="100"
    orthoLeft="-20"
    orthoRight="20"
    orthoTop="20"
    orthoBottom="-20">

    <arashtad-generator
        useBlurExponentialShadowMap="true"
        blurKernel="64"
        blurScale="20">
    </arashtad-generator>

    <arashtad-caster ref="model_1"></arashtad-caster>

    <arashtad-receiver ref="ground"></arashtad-receiver>
    <arashtad-receiver ref="wall_back"></arashtad-receiver>
    <arashtad-receiver ref="wall_left"></arashtad-receiver>

</arashtad-shadow>
