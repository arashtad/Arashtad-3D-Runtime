Shadow Caster

Configure a mesh as a shadow caster and project its shadow onto a receiving surface.

Shadows Caster
Shadow caster: model_1
Shadow receiver: ground

What this demonstrates

A runtime shadow caster reference adds the selected mesh or model meshes to the Babylon.js ShadowGenerator.

Caster Reference

The caster element references the imported model, allowing its meshes to contribute to the generated shadow.

Shadow Projection

The model casts its shadow onto the ground receiver configured by the same ShadowGenerator.

Source

Reference the model with arashtad-caster to configure it as a shadow caster. 

<arashtad-shadow
    light="directional"
    mapSize="2048"
    darkness="0.3"
    minZ="0.1"
    maxZ="100"
    orthoLeft="-20"
    orthoRight="20"
    orthoTop="20"
    orthoBottom="-20">

    <arashtad-generator
        useBlurExponentialShadowMap="true"
        blurKernel="64"
        blurScale="20">
    </arashtad-generator>

    <arashtad-caster ref="model_1"></arashtad-caster>
    <arashtad-receiver ref="ground"></arashtad-receiver>

</arashtad-shadow>
