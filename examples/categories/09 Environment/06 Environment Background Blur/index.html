Control the blur applied to the visible environment background with the environmentBackgroundBlur attribute.

Environment Background Blur

The environmentBackgroundBlur attribute controls the amount of blur applied to the visible environment background.

No Blur 
environmentBackgroundBlur="0"

A value of 0 leaves the environment background unblurred.

Increased Blur 
environmentBackgroundBlur="0.35"

Increasing the value produces a softer environment background.

Background Configuration

Background blur is used together with the environment texture and background rendering settings.

Environment 
environment="../../../assets/environments/room.hdr"
Background 
environmentBackground="true"
environmentBackgroundBlur="0.35"

Blur and Environment Intensity

Background blur and environment intensity control different aspects of the environment.

Background Blur

environmentBackgroundBlur changes the appearance of the visible background.

Environment Intensity

environmentIntensity controls the strength of the environment contribution to the scene.

Source

The background blur is configured directly through arashtad-runtime. 

<arashtad-runtime
    resize="engine.resize()"
    environment="../../../assets/environments/room.hdr"
    environmentIntensity="1"
    environmentBackground="true"
    environmentBackgroundBlur="0.35">
</arashtad-runtime>
