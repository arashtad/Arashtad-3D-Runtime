Display the HDR environment as the scene background with the environmentBackground attribute.

Environment Background

Enable the environment as the visible background while continuing to use the same environment for scene illumination.

Enable Background 
<arashtad-runtime
    environment="../../../assets/environments/room.hdr"
    environmentBackground="true">
</arashtad-runtime>
Disable Background

Setting the attribute to false keeps the environment available without displaying it as the scene background. 

environmentBackground="false"

Background and Lighting

Background rendering and environment intensity are separate controls.

Background

environmentBackground controls whether the environment is visible behind scene objects. 

environmentBackground="true"
Intensity

environmentIntensity controls the strength of the environment contribution. 

environmentIntensity="1"

Background Blur

The environment background can be combined with environment background blur.

Sharp Background 
environmentBackground="true"
environmentBackgroundBlur="0"
Blurred Background 
environmentBackground="true"
environmentBackgroundBlur="0.1"

Source

The environment background is configured directly on the arashtad-runtime element. 

<arashtad-runtime
    resize="engine.resize()"
    environment="../../../assets/environments/room.hdr"
    environmentIntensity="1"
    environmentBackground="true"
    environmentBackgroundBlur="0.1">
</arashtad-runtime>
