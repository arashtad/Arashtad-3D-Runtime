Production-Style Environment Configuration

Advanced Environment Scene

121

Combines HDR environment lighting, background visibility, background blur, environment intensity, environment rotation, imported geometry, materials, and explicit scene lighting in one complete environment configuration.

Advanced HDR Environment Environment intensity, visible background, background blur, and Y-axis environment rotation work together with direct scene lighting and material response.

Advanced Environment Controls

Multiple environment properties can be configured together on the runtime element.

Environment

The HDR file is loaded through the environment attribute.

environmentIntensity controls the strength of the environment's lighting contribution.

environmentBackground determines whether the HDR environment is visible behind the scene.

Background

environmentBackgroundBlur controls the amount of blur applied to the visible environment.

environmentRotationY rotates the environment around the Y axis without changing the geometry of the scene.

Environment and Scene Objects

The environment operates alongside ordinary runtime scene objects, materials, cameras, and lights.

Materials

The metallic sphere demonstrates environment response through its specular properties.

The accent box, dark cylinder, torus, and ground use separate StandardMaterial definitions.

Lighting

The HDR environment provides image-based illumination while the hemispheric and directional lights add explicit direct lighting.

All lighting sources affect the same Babylon.js scene.

Complete Configuration

The environment settings used by this scene.

HDR

environment="../../../assets/environments/room.hdr"

environmentIntensity="1"

environmentBackground="true"

Background

environmentBackgroundBlur="0.2"

environmentRotationY="1"

The rotation value is expressed in radians.

Source

Complete advanced environment scene configuration. 

<canvas
    id="advanced-environment-scene"
    clearColor="new BABYLON.Color4(0.025, 0.035, 0.032, 1)">

    <arashtad-runtime
        resize="engine.resize()"
        environment="../../../assets/environments/room.hdr"
        environmentIntensity="1"
        environmentBackground="true"
        environmentBackgroundBlur="0.2"
        environmentRotationY="1">
    </arashtad-runtime>

    <arashtad-camera
        id="camera"
        type="ArcRotateCamera"
        alpha="1.57"
        beta="1.15"
        radius="13"
        target="new BABYLON.Vector3(0, 1.4, 0)"
        lowerRadiusLimit="5"
        upperRadiusLimit="22"
        wheelDeltaPercentage="0.01">
    </arashtad-camera>

    <arashtad-light
        id="hemispheric-light"
        type="HemisphericLight"
        direction="new BABYLON.Vector3(0, 1, 0)"
        intensity="0.35">
    </arashtad-light>

    <arashtad-light
        id="directional-light"
        type="DirectionalLight"
        direction="new BABYLON.Vector3(-0.5, -1, -0.75)"
        position="new BABYLON.Vector3(5, 8, 4)"
        intensity="1.5">
    </arashtad-light>

    <arashtad-material
        id="metal-material"
        type="StandardMaterial"
        diffuseColor="new BABYLON.Color3(0.18, 0.2, 0.2)"
        specularColor="new BABYLON.Color3(1, 1, 1)">
    </arashtad-material>

    <arashtad-material
        id="accent-material"
        type="StandardMaterial"
        diffuseColor="new BABYLON.Color3(0.15, 0.64, 0.55)"
        specularColor="new BABYLON.Color3(0.85, 0.85, 0.85)">
    </arashtad-material>

    <arashtad-material
        id="dark-material"
        type="StandardMaterial"
        diffuseColor="new BABYLON.Color3(0.035, 0.045, 0.042)"
        specularColor="new BABYLON.Color3(0.5, 0.5, 0.5)">
    </arashtad-material>

    <arashtad-mesh
        type="Sphere"
        id="main-sphere"
        diameter="3"
        segments="48"
        position="new BABYLON.Vector3(0, 2.1, 0)"
        material="metal-material">
    </arashtad-mesh>

    <arashtad-mesh
        type="Box"
        id="left-box"
        width="2.2"
        height="2.2"
        depth="2.2"
        position="new BABYLON.Vector3(-3.4, 1.1, 0)"
        material="accent-material">
    </arashtad-mesh>

    <arashtad-mesh
        type="Cylinder"
        id="right-cylinder"
        height="2.5"
        diameter="2.3"
        tessellation="48"
        position="new BABYLON.Vector3(3.4, 1.25, 0)"
        material="dark-material">
    </arashtad-mesh>

    <arashtad-mesh
        type="Torus"
        id="front-ring"
        diameter="4.8"
        thickness="0.12"
        tessellation="64"
        position="new BABYLON.Vector3(0, 0.9, 2.2)"
        rotation="new BABYLON.Vector3(1.5708, 0, 0)"
        material="accent-material">
    </arashtad-mesh>

    <arashtad-mesh
        type="Ground"
        id="ground"
        width="16"
        height="16"
        position="new BABYLON.Vector3(0, -0.01, 0)"
        material="dark-material">
    </arashtad-mesh>
