Image-Based Environment Lighting

HDR Environment

112

Use a high dynamic range environment to illuminate a 3D scene and provide realistic environment reflections and background imagery through the arashtad-runtime element.

HDR Environment

An HDR environment provides high dynamic range image-based lighting for the scene.

HDR File

Set the environment attribute to the HDR file that should be used by the runtime. 

<arashtad-runtime
    environment="../../../assets/environments/room.hdr">
</arashtad-runtime>
Environment Lighting

The environment contributes lighting to the scene. Its strength is controlled with environmentIntensity. 

environmentIntensity="1"

Environment Background

The HDR image can also be displayed directly as the scene background.

Enable Background

Set environmentBackground to true to display the HDR environment behind the scene. 

environmentBackground="true"
Complete Setup 
<arashtad-runtime
    resize="engine.resize()"
    environment="../../../assets/environments/room.hdr"
    environmentIntensity="1"
    environmentBackground="true">
</arashtad-runtime>

HDR Reflections

Materials in the scene can respond to the environment, making reflective and specular surfaces useful for demonstrating HDR lighting.

Reflective Surface

The metallic sphere uses a strong specular response so the HDR environment contributes visible highlights across its surface.

Scene Objects

Different materials can be placed in the same environment to observe how their surface properties respond to the HDR lighting.

Source

The HDR environment is configured directly through arashtad-runtime. 

<arashtad-runtime
    resize="engine.resize()"
    environment="../../../assets/environments/room.hdr"
    environmentIntensity="1"
    environmentBackground="true">
</arashtad-runtime>

<arashtad-material
    type="StandardMaterial"
    id="metal-material"
    diffuseColor="new BABYLON.Color3(0.12, 0.14, 0.16)"
    specularColor="new BABYLON.Color3(1, 1, 1)"
    specularPower="128">
</arashtad-material>

<arashtad-mesh
    type="Sphere"
    id="metal-sphere"
    diameter="2.6"
    segments="64"
    position="new BABYLON.Vector3(-2.4, 1.4, 0)"
    material="metal-material">
</arashtad-mesh>
