Environment + Models

119

Combines an HDR environment with an imported 3D model. The environment provides image-based lighting and reflections while the model remains fully interactive through the ArcRotateCamera.

HDR Environment The room environment illuminates the imported model and provides its surrounding image-based lighting.

Environment + Imported Model

The HDR environment is active at the same time as the imported model, allowing the model's materials to respond to the environment's image-based lighting.

Environment

The environment attribute loads the HDR environment and makes it available to the scene. environmentIntensity controls the strength of its lighting contribution.

With environmentBackground="true", the HDR image is also rendered as the visible scene background.

Model

The <arashtad-model> element imports the GLB file into the same scene. The model can be positioned, scaled, and viewed using the ArcRotateCamera.

The environment does not replace the imported model. Both are part of the same Babylon.js scene.

Configuration

The important runtime attributes used to combine the HDR environment with the imported model.

HDR Environment

environment="../../../assets/environments/room.hdr" loads the HDR environment.

environmentIntensity="1" keeps the environment lighting at its default strength.

environmentBackground="true" displays the environment around the model.

environmentBackgroundBlur="0.15" applies a small amount of background blur while keeping the environment active for lighting.

Camera

The ArcRotateCamera orbits around the imported model. Mouse or trackpad input rotates the view, while the wheel changes the viewing distance.

The runtime automatically assigns the declared camera as the scene's active camera.

Source

Complete environment and model configuration. 

<canvas
    id="environment-models-scene"
    clearColor="new BABYLON.Color4(0.025, 0.035, 0.032, 1)">

    <arashtad-runtime
        resize="engine.resize()"
        environment="../../../assets/environments/room.hdr"
        environmentIntensity="1"
        environmentBackground="true"
        environmentBackgroundBlur="0.15">
    </arashtad-runtime>

    <arashtad-camera
        id="camera"
        type="ArcRotateCamera"
        alpha="1.57"
        beta="1.2"
        radius="12"
        target="new BABYLON.Vector3(0, 1.5, 0)"
        lowerRadiusLimit="5"
        upperRadiusLimit="20"
        wheelDeltaPercentage="0.01">
    </arashtad-camera>

    <arashtad-light
        id="fill-light"
        type="HemisphericLight"
        direction="new BABYLON.Vector3(0, 1, 0)"
        intensity="0.35">
    </arashtad-light>

    <arashtad-model
        id="product-model"
        src="../../../assets/3d/linux.glb"
        position="new BABYLON.Vector3(0, 0, 0)"
        scaling="new BABYLON.Vector3(7, 7, 7)">
    </arashtad-model>

    <arashtad-mesh
        type="Ground"
        id="ground"
        width="14"
        height="14"
        position="new BABYLON.Vector3(0, -0.01, 0)">
    </arashtad-mesh>

</canvas>
