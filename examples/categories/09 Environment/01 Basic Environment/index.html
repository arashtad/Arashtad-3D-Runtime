Environment Configuration

Basic Environment

111

Configure an HDR environment for scene lighting, reflections, background rendering, blur, and environment rotation using the arashtad-runtime element.

HDR Environment

An HDR environment can provide image-based lighting, reflections, and a visible environment background for the scene.

Environment File

The environment attribute points directly to the HDR environment file. 

<arashtad-runtime
    environment="../../../assets/environments/room.hdr">
</arashtad-runtime>
Environment Intensity

environmentIntensity controls the strength of the environment contribution to the scene. 

environmentIntensity="1"

Environment Background

The same HDR environment can be rendered as the visible background behind the scene.

Background

Set environmentBackground to true to display the environment behind the scene. 

environmentBackground="true"
Background Blur

environmentBackgroundBlur controls the amount of blur applied to the environment background. 

environmentBackgroundBlur="0.1"

Environment Rotation

Rotate the environment independently from the geometry in the scene.

Y-Axis Rotation

Use environmentRotationY to rotate the environment around the Y axis. 

environmentRotationY="1"
Lazy Loading

The lazy attribute enables the runtime's lazy-loading behavior. 

<arashtad-runtime
    lazy
    resize="engine.resize()"
    environment="../../../assets/environments/room.hdr"
    environmentIntensity="1"
    environmentBackground="true"
    environmentBackgroundBlur="0.1"
    environmentRotationY="1">
</arashtad-runtime>

Source

The environment is configured declaratively through the runtime element. 

<arashtad-runtime
    lazy
    resize="engine.resize()"
    environment="../../../assets/environments/room.hdr"
    environmentIntensity="1"
    environmentBackground="true"
    environmentBackgroundBlur="0.1"
    environmentRotationY="1">
</arashtad-runtime>

    minZ="0.1"
    maxZ="1000"

</arashtad-camera>
