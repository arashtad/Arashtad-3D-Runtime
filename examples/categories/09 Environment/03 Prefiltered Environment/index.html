Prefiltered Environment

113

Use an HDR environment texture as the source for environment lighting, reflections, and background rendering.

Prefiltered Environment

An HDR environment texture provides the source data for environment lighting and reflections.

Environment Texture

The environment attribute points to the HDR environment texture. 

<arashtad-runtime
    environment="../../../assets/environments/room.hdr">
</arashtad-runtime>
Environment Intensity

Control the strength of the environment contribution with environmentIntensity. 

environmentIntensity="1"

Environment Background

The same environment can be displayed as the visible background of the scene.

Enable Background

Set environmentBackground to true to display the environment behind the scene. 

environmentBackground="true"
Complete Configuration 
<arashtad-runtime
    resize="engine.resize()"
    environment="../../../assets/environments/room.hdr"
    environmentIntensity="1"
    environmentBackground="true">
</arashtad-runtime>

Material Response

Different materials respond differently to the same environment illumination and reflection data.

Metallic Surface

The metallic sphere uses a strong specular response to make the environment highlights visible.

Multiple Surfaces

The scene uses metallic, colored, and dark materials to demonstrate different responses to the environment.

Source

The environment is configured declaratively through arashtad-runtime. 

<arashtad-runtime
    resize="engine.resize()"
    environment="../../../assets/environments/room.hdr"
    environmentIntensity="1"
    environmentBackground="true">
</arashtad-runtime>

<arashtad-material
    type="StandardMaterial"
    id="metal-material"
    diffuseColor="new BABYLON.Color3(0.12, 0.14, 0.16)"
    specularColor="new BABYLON.Color3(1, 1, 1)"
    specularPower="128">
</arashtad-material>

<arashtad-mesh
    type="Sphere"
    id="metal-sphere"
    diameter="2.6"
    segments="64"
    position="new BABYLON.Vector3(-2.8, 1.4, 0)"
    material="metal-material">
</arashtad-mesh>
