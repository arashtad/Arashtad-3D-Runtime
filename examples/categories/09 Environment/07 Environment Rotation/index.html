Environment Rotation

117

Control the horizontal orientation of the environment with the environmentRotationY attribute.

Environment Rotation

Rotate the environment around the Y axis without changing the position or orientation of scene objects.

Rotation Property

Use environmentRotationY to set the environment's horizontal rotation. 

environmentRotationY="1"
Radians

The value is expressed in radians. A value of 0 represents the default orientation. 

environmentRotationY="0"
environmentRotationY="1"
environmentRotationY="3.14159"

Orientation and Background

When the environment is used as the background, rotating it changes the visible orientation of the surrounding environment.

Visible Background 
environmentBackground="true"

The rotated environment remains visible behind the scene objects.

Environment Intensity 
environmentIntensity="1"

Rotation changes orientation, while intensity controls the environment contribution.

Rotation and Background Blur

Environment rotation can be combined with background blur to control both orientation and appearance.

Rotation 
environmentRotationY="1"
Blur 
environmentBackgroundBlur="0.1"

Source

Environment rotation is configured directly through arashtad-runtime. 

<arashtad-runtime
    resize="engine.resize()"
    environment="../../../assets/environments/room.hdr"
    environmentIntensity="1"
    environmentBackground="true"
    environmentBackgroundBlur="0.1"
    environmentRotationY="1">
</arashtad-runtime>
