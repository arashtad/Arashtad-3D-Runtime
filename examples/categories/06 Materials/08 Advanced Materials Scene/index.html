Combine externally defined materials, mesh-local materials, and material references applied to imported model meshes.

External + Inline + Model Mesh Materials

Material Configurations

The scene demonstrates external material references, materials declared inside mesh elements, and material references applied directly to imported model meshes.

Configurations

Box - Uses an externally defined material reference.

Sphere - Contains its material declaration inside the mesh element.

Model mesh - Uses a material reference on an imported mesh identified by its runtime reference.

Source

Materials can be defined independently and referenced by meshes. Materials can also be nested inside mesh elements, while imported model meshes can be targeted through their runtime references. 

<arashtad-material
    type="StandardMaterial"
    id="external-box-material"
    diffuseColor="new BABYLON.Color3(0.15, 0.64, 0.55)"
    specularColor="new BABYLON.Color3(0.8, 0.8, 0.8)"
    specularPower="64">
</arashtad-material>

<arashtad-mesh
    type="Box"
    id="external-material-mesh"
    width="3"
    height="3"
    depth="3"
    position="new BABYLON.Vector3(-3.5, 1.5, 0)"
    material="external-box-material">
</arashtad-mesh>

<arashtad-mesh
    type="Sphere"
    id="inline-material-mesh"
    diameter="3"
    position="new BABYLON.Vector3(0.3, 1.5, 0)">

    <arashtad-material
        type="StandardMaterial"
        id="inline-sphere-material"
        diffuseColor="new BABYLON.Color3(1, 0.56, 0.08)"
        specularColor="new BABYLON.Color3(0.8, 0.8, 0.8)"
        specularPower="64">
    </arashtad-material>

</arashtad-mesh>

<arashtad-material
    type="StandardMaterial"
    id="external-model-material"
    diffuseColor="new BABYLON.Color3(0.35, 0.45, 0.9)"
    specularColor="new BABYLON.Color3(0.8, 0.8, 0.8)"
    specularPower="64">
</arashtad-material>

<arashtad-model
    id="external-material-model"
    src="../../../assets/3d/linux.glb"
    position="new BABYLON.Vector3(3.5, 0, 0)"
    scaling="new BABYLON.Vector3(5, 5, 5)">

    <arashtad-mesh
        ref="black"
        material="external-model-material">
    </arashtad-mesh>

</arashtad-model>
