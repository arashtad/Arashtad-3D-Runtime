Configure the appearance of a StandardMaterial using diffuse, specular, emissive, and surface properties.

StandardMaterial
Diffuse · Specular · Emissive · Power

Material Properties

StandardMaterial properties control the base color, highlights, self-illumination, and specular response of a mesh.

Properties

Diffuse Color - Base surface color.

Specular Color - Color of reflected highlights.

Emissive Color - Adds self-illumination to the material.

Specular Power - Controls the sharpness of the specular highlight.

Source

Material properties are declared directly as attributes on the runtime material element. 

<arashtad-material
    type="StandardMaterial"
    id="property-material"
    diffuseColor="new BABYLON.Color3(0.15, 0.64, 0.55)"
    specularColor="new BABYLON.Color3(0.9, 0.9, 0.9)"
    emissiveColor="new BABYLON.Color3(0.02, 0.08, 0.07)"
    specularPower="64">
</arashtad-material>

<arashtad-mesh
    type="Box"
    id="material-box"
    size="2.5"
    position="new BABYLON.Vector3(0, 1.25, 0)"
    material="property-material">
</arashtad-mesh>
