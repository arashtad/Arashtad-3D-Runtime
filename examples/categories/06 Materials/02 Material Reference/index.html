1 Shared Material

Referencing a Material

A material can be declared once and assigned to multiple meshes using the material reference.

Shared Material

Material - StandardMaterial

Reference - shared-material

Meshes - Box, Sphere, Cylinder

Diffuse Color - Teal

Source

The same material reference is assigned to three different mesh types. 

<arashtad-material
    type="StandardMaterial"
    id="shared-material"
    diffuseColor="new BABYLON.Color3(0.15, 0.64, 0.55)"
    specularColor="new BABYLON.Color3(0.8, 0.8, 0.8)">
</arashtad-material>

<arashtad-mesh
    type="Box"
    id="left-box"
    size="2"
    position="new BABYLON.Vector3(-2.4, 1, 0)"
    material="shared-material">
</arashtad-mesh>

<arashtad-mesh
    type="Sphere"
    id="center-sphere"
    diameter="2"
    segments="32"
    position="new BABYLON.Vector3(0, 1, 0)"
    material="shared-material">
</arashtad-mesh>

<arashtad-mesh
    type="Cylinder"
    id="right-cylinder"
    height="2"
    diameter="1.8"
    tessellation="32"
    position="new BABYLON.Vector3(2.4, 1, 0)"
    material="shared-material">
</arashtad-mesh>
