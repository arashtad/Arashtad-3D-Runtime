Combine multiple independent materials with multiple meshes to create a composed scene with distinct surface appearances.

Materials Across Multiple Meshes

Independent materials can be assigned to individual meshes, while the same material can also be shared by multiple meshes.

Scene Composition

Base - Box using base-material

Columns - Two Cylinders sharing column-material

Top - Sphere using top-material

Ground - Ground mesh using the default material

Source

Materials are declared independently, then assigned to multiple meshes through material references. 

<arashtad-material
    type="StandardMaterial"
    id="base-material"
    diffuseColor="new BABYLON.Color3(0.15, 0.64, 0.55)"
    specularColor="new BABYLON.Color3(0.8, 0.8, 0.8)"
    specularPower="64">
</arashtad-material>

<arashtad-material
    type="StandardMaterial"
    id="column-material"
    diffuseColor="new BABYLON.Color3(0.35, 0.45, 0.9)"
    specularColor="new BABYLON.Color3(0.8, 0.8, 0.8)"
    specularPower="64">
</arashtad-material>

<arashtad-material
    type="StandardMaterial"
    id="top-material"
    diffuseColor="new BABYLON.Color3(1, 0.56, 0.08)"
    specularColor="new BABYLON.Color3(0.8, 0.8, 0.8)"
    specularPower="64">
</arashtad-material>

<arashtad-mesh
    type="Box"
    id="base-mesh"
    width="5"
    height="0.6"
    depth="3"
    position="new BABYLON.Vector3(0, 0.3, 0)"
    material="base-material">
</arashtad-mesh>

<arashtad-mesh
    type="Cylinder"
    id="left-column"
    height="3"
    diameter="1"
    tessellation="24"
    position="new BABYLON.Vector3(-1.8, 1.8, 0)"
    material="column-material">
</arashtad-mesh>

<arashtad-mesh
    type="Cylinder"
    id="right-column"
    height="3"
    diameter="1"
    tessellation="24"
    position="new BABYLON.Vector3(1.8, 1.8, 0)"
    material="column-material">
</arashtad-mesh>

<arashtad-mesh
    type="Sphere"
    id="top-mesh"
    diameter="2"
    position="new BABYLON.Vector3(0, 3.4, 0)"
    material="top-material">
</arashtad-mesh>
