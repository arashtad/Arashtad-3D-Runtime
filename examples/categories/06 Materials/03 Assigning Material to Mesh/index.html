Assign a declared material to a runtime mesh by referencing the material directly from the mesh element.

Assigned to Box

Assigning a Material

A mesh can receive a previously declared material through its material attribute.

Assignment

Material - box-material

Mesh - Box

Assignment - material="box-material"

Type - StandardMaterial

Source

Declare the material first, then reference it from the mesh using its registered ID. 

<arashtad-material
    type="StandardMaterial"
    id="box-material"
    diffuseColor="new BABYLON.Color3(0.15, 0.64, 0.55)"
    specularColor="new BABYLON.Color3(0.8, 0.8, 0.8)">
</arashtad-material>

<arashtad-mesh
    type="Box"
    id="box"
    size="2.5"
    position="new BABYLON.Vector3(0, 1.25, 0)"
    material="box-material">
</arashtad-mesh>
