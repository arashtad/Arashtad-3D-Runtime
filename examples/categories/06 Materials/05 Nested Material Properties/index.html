Modify nested Babylon.js material properties directly through dot notation in runtime attributes.

Nested Color Properties

Nested Property Access

Runtime attributes can address properties inside Babylon.js objects using dot notation.

Material Properties

Diffuse color - diffuseColor.r, diffuseColor.g, diffuseColor.b

Specular color - specularColor.r, specularColor.g, specularColor.b

Emissive color - emissiveColor.r, emissiveColor.g, emissiveColor.b

Specular power - direct material property

Source

Nested properties use dot notation in the attribute name. The runtime resolves each property path and assigns the supplied value. 

<arashtad-material
    type="StandardMaterial"
    id="nested-material"
    diffuseColor.r="0.15"
    diffuseColor.g="0.64"
    diffuseColor.b="0.55"
    specularColor.r="0.8"
    specularColor.g="0.8"
    specularColor.b="0.8"
    emissiveColor.r="0.02"
    emissiveColor.g="0.08"
    emissiveColor.b="0.06"
    specularPower="64">
</arashtad-material>
