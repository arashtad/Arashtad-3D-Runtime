Multiple Materials

91

Create multiple independent materials and assign each one to a different mesh in the same scene.

3 Materials · 3 Meshes

Independent Materials

Each material is declared independently and assigned to its corresponding mesh by reference.

Material Assignment

Box - box-material

Sphere - sphere-material

Cylinder - cylinder-material

Ground - default material

Source

Multiple material elements can coexist in the same scene, with each mesh referencing its required material by ID. 

<arashtad-material
    type="StandardMaterial"
    id="box-material"
    diffuseColor="new BABYLON.Color3(0.15, 0.64, 0.55)"
    specularColor="new BABYLON.Color3(0.8, 0.8, 0.8)">
</arashtad-material>

<arashtad-material
    type="StandardMaterial"
    id="sphere-material"
    diffuseColor="new BABYLON.Color3(1, 0.56, 0.08)"
    specularColor="new BABYLON.Color3(0.8, 0.8, 0.8)">
</arashtad-material>

<arashtad-material
    type="StandardMaterial"
    id="cylinder-material"
    diffuseColor="new BABYLON.Color3(0.35, 0.45, 0.9)"
    specularColor="new BABYLON.Color3(0.8, 0.8, 0.8)">
</arashtad-material>

<arashtad-mesh
    type="Box"
    id="box-mesh"
    width="2.5"
    height="2.5"
    depth="2.5"
    position="new BABYLON.Vector3(-3, 1.25, 0)"
    material="box-material">
</arashtad-mesh>

<arashtad-mesh
    type="Sphere"
    id="sphere-mesh"
    diameter="2.5"
    position="new BABYLON.Vector3(0, 1.25, 0)"
    material="sphere-material">
</arashtad-mesh>

<arashtad-mesh
    type="Cylinder"
    id="cylinder-mesh"
    height="2.5"
    diameter="2"
    tessellation="32"
    position="new BABYLON.Vector3(3, 1.25, 0)"
    material="cylinder-material">
</arashtad-mesh>
