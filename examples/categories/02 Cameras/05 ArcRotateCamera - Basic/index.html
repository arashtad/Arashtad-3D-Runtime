ArcRotateCamera - Basic

Create a Babylon.js ArcRotateCamera declaratively and use it as the active camera for a simple 3D scene.

Camera ArcRotateCamera Basic

What this demonstrates

The basic declarative setup of an ArcRotateCamera.

ArcRotateCamera

The runtime resolves ArcRotateCamera from Babylon.js and constructs it from the supplied alpha, beta, radius, and target.

Orbit Parameters

The camera starts with an alpha of 45°, beta of 65°, radius of 8, and targets (0, 0, 0).

Source

An ArcRotateCamera is created using the runtime camera tag. 

<canvas id="arcrotate-camera-basic">

    <arashtad-runtime
        resize="engine.resize()">
    </arashtad-runtime>

    <arashtad-camera
        type="ArcRotateCamera"
        id="camera"
        args="BABYLON.Tools.ToRadians(45), BABYLON.Tools.ToRadians(65), 8, new BABYLON.Vector3(0, 0, 0)">
    </arashtad-camera>

    <arashtad-light
        type="HemisphericLight"
        id="light"
        args="new BABYLON.Vector3(0, 1, 0)"
        intensity="1.2">
    </arashtad-light>

    <arashtad-mesh
        type="Box"
        id="box"
        size="2">
    </arashtad-mesh>

</canvas>

<script src="../../../../lib/babylon/babylon.js"></script>

<script type="module">
    import { ready } from '../../../../lib/arashtad/arashtad-3d-runtime-1.1.0.min.js';

    const canvas = document.getElementById('arcrotate-camera-basic');
