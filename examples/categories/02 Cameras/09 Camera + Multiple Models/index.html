Camera + Multiple Models

Use a single ArcRotateCamera to view multiple independently loaded 3D models in the same Babylon.js scene.

Camera ArcRotateCamera Multiple Models

What this demonstrates

Loading multiple independent model instances into one scene and viewing them through a single camera.

Multiple Models

Each arashtad-model element loads linux.glb into the same scene.

Model Positions

The three model roots are positioned at -3, 0, and 3 along the X axis.

Shared Camera

A single ArcRotateCamera orbits around the models.

Source

Three model elements load the same GLB file as separate scene objects. 

<canvas id="camera-multiple-models">

    <arashtad-runtime resize="engine.resize()">
    </arashtad-runtime>

    <arashtad-camera
        type="ArcRotateCamera"
        id="camera"
        args="BABYLON.Tools.ToRadians(45), BABYLON.Tools.ToRadians(65), 10, new BABYLON.Vector3(0, 0.5, 0)"
        lowerRadiusLimit="3"
        upperRadiusLimit="20">
    </arashtad-camera>

    <arashtad-light
        type="HemisphericLight"
        id="light"
        args="new BABYLON.Vector3(0, 1, 0)"
        intensity="1.2">
    </arashtad-light>

    <arashtad-model
        id="model-left"
        src="../../../assets/3d/linux.glb"
        position="new BABYLON.Vector3(-3, 0, 0)">
    </arashtad-model>

    <arashtad-model
        id="model-center"
        src="../../../assets/3d/linux.glb"
        position="new BABYLON.Vector3(0, 0, 0)">
    </arashtad-model>

    <arashtad-model
        id="model-right"
        src="../../../assets/3d/linux.glb"
        position="new BABYLON.Vector3(3, 0, 0)">
    </arashtad-model>

</canvas>
