Advanced Camera Scene

Build an interactive camera control environment with smooth orbit, zoom, and reset operations driven by Babylon.js animations.

Camera ArcRotateCamera Animation Interactive

What this demonstrates

A complete interactive camera-control environment combining declarative scene construction with Babylon.js camera animation.

Camera Control

The scene uses an ArcRotateCamera with configurable alpha, beta, radius, limits, and inertia. Physical scene objects act as camera controls.

Smooth Animation

Camera properties are animated with BABYLON.Animation and an ease-in/ease-out CubicEase transition instead of changing position instantly.

Native Triggers

Each control uses Babylon's native OnPickTrigger directly on the declarative mesh.

Camera Limits

Orbit and zoom operations respect the camera's configured alpha, beta, and radius limits.

Source

Declarative camera controls combined with Babylon.js animation for smooth transitions.

<script>
window.animateCameraProperty = function (camera, property, target) {
    const animation = new BABYLON.Animation(
        `camera-${property}`,
        property,
        60,
        BABYLON.Animation.ANIMATIONTYPE_FLOAT,
        BABYLON.Animation.ANIMATIONLOOPMODE_CONSTANT
    );

    animation.setKeys([
        {
            frame: 0,
            value: camera[property]
        },
        {
            frame: 30,
            value: target
        }
    ]);

    const easing = new BABYLON.CubicEase();

    easing.setEasingMode(
        BABYLON.EasingFunction.EASINGMODE_EASEINOUT
    );

    animation.setEasingFunction(easing);

    scene.beginDirectAnimation(
        camera,
        [animation],
        0,
        30,
        false
    );
};
</script>
