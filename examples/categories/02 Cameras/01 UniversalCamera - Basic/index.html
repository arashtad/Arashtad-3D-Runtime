UniversalCamera - Basic

Create a Babylon.js UniversalCamera declaratively and use it as the active camera for a simple 3D scene.

Camera UniversalCamera Basic

What this demonstrates

The basic declarative setup of a UniversalCamera.

UniversalCamera

The runtime resolves UniversalCamera from Babylon.js and constructs it from the supplied position.

Position

The camera starts at (0, 2, -8), looking toward the scene through the active camera system.

Source

A UniversalCamera is created using the runtime camera tag. 

<canvas id="universal-camera-basic">

    <arashtad-runtime
        resize="engine.resize()">
    </arashtad-runtime>

    <arashtad-camera
        type="UniversalCamera"
        id="camera"
        args="new BABYLON.Vector3(0, 2, -8)">
    </arashtad-camera>

    <arashtad-light
        type="HemisphericLight"
        id="light"
        args="new BABYLON.Vector3(0, 1, 0)"
        intensity="1.2">
    </arashtad-light>

    <arashtad-mesh
        type="Box"
        id="box"
        size="2">
    </arashtad-mesh>

</canvas>

<script src="../../../../lib/babylon/babylon.js"></script>

<script type="module">
    import { ready } from '../../../../lib/arashtad/arashtad-3d-runtime-1.1.0.min.js';

    const canvas = document.getElementById('universal-camera-basic');

    await ready(canvas);
</script>
