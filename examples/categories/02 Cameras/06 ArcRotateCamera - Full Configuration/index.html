ArcRotateCamera - Full Configuration

Configure an ArcRotateCamera declaratively with orbit, zoom, limits, inertia, and collision properties.

Camera ArcRotateCamera Full Configuration

What this demonstrates

A more complete ArcRotateCamera configuration using declarative Babylon.js properties.

Orbit Limits

Alpha and beta limits constrain horizontal and vertical camera rotation, while radius limits constrain the zoom range.

Inertia & Zoom

Camera inertia, wheel precision, wheel delta percentage, and panning settings control the interaction response.

Camera Range

The camera uses near and far clipping values together with bounded orbit and radius ranges.

Source

Full ArcRotateCamera configuration using runtime properties. 

<canvas id="arcrotate-camera-full">

    <arashtad-runtime
        resize="engine.resize()">
    </arashtad-runtime>

    <arashtad-camera
        type="ArcRotateCamera"
        id="camera"
        args="BABYLON.Tools.ToRadians(45), BABYLON.Tools.ToRadians(65), 10, new BABYLON.Vector3(0, 1, 0)"
        lowerAlphaLimit="BABYLON.Tools.ToRadians(-180)"
        upperAlphaLimit="BABYLON.Tools.ToRadians(180)"
        lowerBetaLimit="BABYLON.Tools.ToRadians(15)"
        upperBetaLimit="BABYLON.Tools.ToRadians(85)"
        lowerRadiusLimit="4"
        upperRadiusLimit="20"
        inertialAlphaOffset="0"
        inertialBetaOffset="0"
        inertialRadiusOffset="0"
        inertia="0.85"
        wheelPrecision="50"
        wheelDeltaPercentage="0.01"
        minZ="0.1"
        maxZ="1000"
        panningSensibility="1000"
        panningInertia="0.8"
        useBouncingBehavior="true">
    </arashtad-camera>

    <arashtad-light
        type="HemisphericLight"
        id="light"
        args="new BABYLON.Vector3(0, 1, 0)"
        intensity="1.2">
    </arashtad-light>

    <arashtad-mesh
        type="Ground"
        id="ground"
        width="20"
        height="20">
    </arashtad-mesh>

    <arashtad-mesh
        type="Box"
        id="box"
        size="2"
        position="new BABYLON.Vector3(0, 1, 0)">
    </arashtad-mesh>

    <arashtad-mesh
        type="Sphere"
        id="sphere"
        diameter="1.5"
        position="new BABYLON.Vector3(3, 1, 0)">
    </arashtad-mesh>

    <arashtad-mesh
        type="Cylinder"
        id="cylinder"
        height="2"
        diameter="1.5"
        position="new BABYLON.Vector3(-3, 1, 0)">
    </arashtad-mesh>

</canvas>
